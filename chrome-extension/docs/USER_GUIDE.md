# 四柱推命 Chrome拡張機能 ユーザーガイド

この拡張機能は、ブラウザのサイドパネルで四柱推命（子平法）の命式を作成するツールです。バージョン **v1.5.0** では、出生地の地方平均時補正・時差手入力・子時切替に対応しています。

## インストール方法

1. このリポジトリを適当なフォルダにダウンロード（解凍）します。
2. Google Chromeを開き、アドレスバーに `chrome://extensions/` と入力して移動します。
3. 右上の「デベロッパーモード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、ダウンロードしたフォルダの中にある `chrome-extension` フォルダを選択します。
5. ツールバーのパズルアイコンから「四柱推命」拡張機能をピン留めすると便利です。

## 基本的な使い方

### 1. 起動する

ブラウザ右上の拡張機能アイコンをクリックし、「サイドパネルを開く」を選択するか、サイドパネルメニューから「四柱推命」を選択します。

### 2. 情報を入力する

入力欄の順は次のとおりです。

1. **生年月日**: 西暦で入力します（例: 1990年1月1日）。日本標準時（JST）の暦日です。
2. **出生時刻**（任意）: わかる場合のみ入力します。
   - 時だけ入れて分を空にすると、分は `0` として計算します。
   - **時刻を空にした場合、補正は行わず時柱も出しません。** 大運の立運だけ、入力した年月日の **12:00** で計算します。
3. **子時の切替**:
   - **23時切替**（既定）: 23:00〜0:59を子時。23時台は翌日の日柱として扱います。
   - **0時切替**: 0:00〜1:59を子時。23時台は亥時・当日の日柱です。
4. **性別**: 大運の順行・逆行判定に使用します。
5. **出生地（都道府県）**（任意）: 47都道府県から選びます。日本標準時の基準は明石（東経135°）です。東京都を選ぶと地方平均時補正は **+19分** になります。未選択なら経度補正は 0 分です。
6. **標準時からの時差**（任意）: 日本国内のみの場合は 0 のままで構いません。海外出生は、出生地の時計時刻を日本標準時へ合わせる差を入力します。夏時間は手動で時差に含めてください。入力できる範囲は ±23:59 です。

**便利な入力方法**:
- **クリップボード貼り付け**: テキストエリアに「1990/01/01 12:00 男性」のようなテキストを貼り付けると、生年月日・時刻・性別が各フィールドに入ります。都道府県・時差・子時モードは貼り付け対象外なので、必要なら手入力してください。

### 3. 計算する

「計算」ボタンをクリックします。
下にスクロールすると、以下の情報が表示されます。

- **時刻補正サマリ**: 適用時は入力時刻・時差・地方平均時補正・補正後時刻・子時モード。時刻未入力時は「時刻補正: 時刻未入力のため補正・時柱なし」。23時切替で補正後が23時台なら、日柱が翌日扱いになる注記も出ます。
- **命式表**: 年柱、月柱、日柱、時柱（時刻があるとき）
- **通変星・蔵干・十二運**: 各柱の詳細情報
- **大運表**: 立運年齢からの10年ごとの運勢。表示年は補正後の年です（年を跨ぐ補正では補正後の年を使います）。

### 4. 結果を保存する

- **PNG保存**: 結果エリア右上の「PNG保存」を押すと、時刻補正サマリ・命式・大運が画像としてダウンロードされます。

## 時刻補正の要点

補正後時刻は次のとおりです。

```
補正後 = 入力時刻 + 時差 + 地方平均時補正
地方平均時補正（分）= round(4 × (出生地経度 − 135))
```

- 真太陽時は使いません。夏時間の自動判定もありません。
- 補正量 0 分でも「適用」と表示し、内訳を出します。

## 注意事項

- 日時は日本標準時（JST）の数値暦として扱います。
- 1900年〜2100年頃までの節気データに対応しています。
- 本ツールは四柱推命（子平法）です。禄命法ではありません。

## トラブルシューティング

- 計算されない場合: 入力形式が正しいか確認してください（未来の日付や存在しない日付、時差 ±24:00 など）。
- エラーが表示される場合: いったん拡張機能を再読み込み（リロード）してみてください。
