# 03. データマスタと非機能

## 1. 都道府県経度マスタ（確定）

### 1.1 方針

- 日本の都道府県ごとに代表経度（東経, 度）を1つ保持する固定マスタ
- 市区町村分割はしない
- 基準子午線: **135.0**（明石）
- 代表経度: **都道府県庁所在地**
- **47件必須**、`code` は **2桁文字列**

### 1.2 正式スキーマ

配置: `chrome-extension/data/prefecture_longitude.json`（確定）  
読込: `DataLoader.loadPrefectureLongitude()`

```json
{
  "version": "1.0",
  "referenceMeridianEast": 135.0,
  "referenceName": "明石（日本標準時子午線）",
  "longitudeUnit": "degree_east",
  "sourceNote": "都道府県庁所在地の代表経度",
  "prefectures": [
    {
      "code": "13",
      "name": "東京都",
      "longitudeEast": 139.6917
    }
  ]
}
```

補正分:

```
Math.round(4 × (longitudeEast − referenceMeridianEast))
```

東京（139.6917）→ **+19分**。

詳細値は詳細設計 `09_都道府県経度マスタ.md`。

## 2. 非機能要件

| 項目 | 要件 |
|------|------|
| オフライン | 外部APIなしで完結 |
| 日時計算 | JST暦の数値演算。OSタイムゾーンに依存しない |
| 性能 | 補正・子時判定は定数時間 |
| 互換 | 都道府県未選択・時差0・`switch23`・非23時台で V1.0 と実質同結果を目指す |
| 既知差分 | 23時台の日柱日跨ぎ、大運の時分反映 |
| テスト | 補正、子時、節入り、大運、合成境界、PNG |
| 保守 | 経度マスタはデータ変更のみで更新可能 |

## 3. 受入観点（抜粋）

1. 東京・時差0: **+19分**の地方平均時補正
2. 兵庫（明石近傍）: 補正がほぼ0
3. 時差のみ（例 +60分）: 時柱/節入り/大運に反映
4. 時差＋都道府県: 合算
5. 補正で日付・年が変わるケース（表示年も補正後）
6. 時刻未入力: 補正なし、時柱なし、サマリ1行
7. 時のみ入力: 分=0として計算
8. **子時 `switch23`**: 補正後 23:30 → 子時、日柱は翌日（年月柱は `t_corrected` 当日基準）
9. **子時 `switch00`**: 補正後 23:30 → 亥時、日柱は当日
10. **子時両モード**: 補正後 00:30 → いずれも子時
11. 補正で 22時台→23時台、23時台→翌日0時台の境界
12. PNGに補正情報と子時モードが含まれる
13. バージョン表示が `1.5.0`
