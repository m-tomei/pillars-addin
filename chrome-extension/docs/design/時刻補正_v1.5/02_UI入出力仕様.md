# 02. UI・入出力仕様

## 1. 入力フォーム変更

### 1.1 変更後の入力項目と配置順（確定）

| 順 | 項目 | 必須 | 入力方式 | 備考 |
|----|------|------|----------|------|
| 1 | 生年月日 | 必須 | 年/月/日 | 変更なし |
| 2 | 出生時刻 | 任意 | 時/分 | 時のみ入力時は分=0。時が空なら時刻未入力 |
| 3 | 子時の切替 | 必須相当 | ラジオ | 既定: 23時切替 |
| 4 | 性別 | 必須 | ラジオ | 変更なし |
| 5 | 出生地（都道府県） | 任意 | セレクト | 自由テキスト廃止 |
| 6 | 標準時からの時差 | 任意 | 符号＋時間＋分 | 未入力は 0 分 |
| 7 | ボタン群 | — | — | ペースト / クリア / 計算 |

### 1.2 出生地（都道府県）

- UI: `<select>`（「未選択」＋47都道府県）
- 選択肢は経度マスタから生成（単一ソース）
- 未選択時: 地方平均時補正なし
- 自由テキスト欄は廃止
- 不正コードは InputManager でフォームエラー

### 1.3 時差入力（確定）

- 符号: `+` / `-`
- 時間: 整数 0–23
- 分: 0–59
- 内部正規化: 分単位（例: `+5:30` → `+330`）
- 許容範囲: **-23:59 〜 +23:59**
- ヘルプテキスト:  
  `日本国内のみの場合は 0 のままで構いません。海外出生は、出生地の時計時刻を日本標準時へ合わせる差を入力します。夏時間は手動で時差に含めてください。`

### 1.4 子時切替（確定）

| 表示ラベル | 値 |
|------------|-----|
| 23時切替 | `switch23` |
| 0時切替 | `switch00` |

- 既定値: **23時切替**
- 未送信: `switch23`
- 定義外: 入力エラー
- 補足文:
  - 23時切替: `23:00〜0:59を子時。23時台は翌日の日柱として扱います`
  - 0時切替: `0:00〜1:59を子時。23時台は亥時・当日の日柱です`

### 1.5 補正のON/OFF

- トグルは設けない（常時ON）
- 未入力項目は補正量0

### 1.6 時刻の部分入力

| 時 | 分 | 扱い |
|----|----|------|
| 空 | （任意） | 時刻未入力。補正なし・時柱なし |
| あり | 空 | **分=0** として補正・計算 |
| あり | あり | そのまま |

## 2. バリデーション

| 項目 | ルール |
|------|--------|
| 時差（時間） | 0–23 |
| 時差（分） | 0–59 |
| 時差合計 | -23:59〜+23:59 |
| 都道府県 | 未選択、またはマスタに存在する code |
| 子時モード | 空→`switch23`。定義外→エラー |

## 3. 結果表示（確定）

命式テーブルの直前に補正サマリを置く。

### 時刻あり

```
時刻補正: 適用
入力時刻: 1990-05-01 08:30
時差: +00:00（0分）
地方平均時補正: +19分（東京都 / 東経139.6917°）
補正後時刻: 1990-05-01 08:49
子時モード: 23時切替
```

- 補正量合計が0でも内訳を表示する（`applied: true`）
- `switch23` かつ補正後23時台なら、日柱翌日扱いの注記を追加

### 時刻なし（確定）

1行表示:

```
時刻補正: 時刻未入力のため補正・時柱なし
```

## 4. PNG出力

- 結果エリア内の補正サマリ・子時モードを既存PNG保存対象に含める
- 最低限載せる情報: 入力時刻、時差、地方平均時補正、補正後時刻、子時モード（または時刻なし1行）

- 大運など結果表示で用いる基準年は **計算に使った年**（補正適用時は `t_corrected.year`）とする
