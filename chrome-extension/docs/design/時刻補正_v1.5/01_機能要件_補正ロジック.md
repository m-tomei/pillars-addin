# 01. 機能要件（補正ロジック）

## 1. 用語

| 用語 | 定義 |
|------|------|
| 入力時刻 | 利用者が入力した出生地の時計時刻（時・分） |
| 時差オフセット | 標準時からの手入力補正量（分）。符号付き |
| 地方平均時補正量 | 出生地経度と明石子午線の差から求める分補正 |
| `t_corrected` | 時差＋地方平均時を合成した補正後日時（JST暦の数値） |
| 基準子午線 | 東経 135.0°（明石＝日本標準時の基準） |
| 子時モード | 時支境界の取り方。`switch23` または `switch00` |
| `resolveDayPillarDate` | 子時モードに応じ日柱用の暦日を返す関数（日柱・時干専用） |

## 2. 補正の適用条件

| 条件 | 時差補正（C） | 地方平均時補正（A） | 計算への適用 |
|------|---------------|---------------------|--------------|
| 時刻未入力（時が空） | しない | しない | 時柱なし。補正サマリは1行表示 |
| 時のみ入力・分空 | 手入力値（既定0） | 条件次第 | **分は0として扱う** |
| 時刻あり・都道府県未選択・時差0 | 0分 | しない | `t_corrected`＝入力時刻＋子時モード |
| 時刻あり・都道府県選択あり | 手入力値（既定0） | する | 両方を加算したうえで子時モード適用 |
| 時刻あり・都道府県なし・時差のみ | 手入力値 | しない | 時差のみ＋子時モード |

補足: 「常時ON」はトグルでOFFにしない意味。入力が無い項目の補正はスキップする。

## 3. 計算式

### 3.1 時差補正（C）

```
t_after_tz = t_input + offset_minutes
```

- `offset_minutes`: 手入力。UIは時間+分+符号、内部は分
- 符号の定義（確定）: **出生地の時計時刻を JST に合わせるための加算分を正**
  - 国内（すでにJST）は通常 `0`
  - 例: 出生地時計が JST より 5 時間遅れなら `+5:00`（+300分）

### 3.2 地方平均時補正（A）

```
longitude_offset_minutes = Math.round(4 × (longitudeEast − 135.0))
```

- 経度1°あたり4分、整数分へ四捨五入（`Math.round`）
- 例: 東京 139.6917 → `4×4.6917=18.7668` → **+19分**
- 真太陽時・均時差は加えない

### 3.3 合成

```
t_corrected = t_input + offset_minutes + longitude_offset_minutes
```

- 演算は **JST暦の数値年月日時分** に対する分加算とする（OSローカルTZの `Date` に依存しない）
- 節入り・大運の時刻比較は **`toJstEpochMillis` と節気ISO（`+09:00` 保持）の epoch 比較** とする
- 分の繰り上がり/繰り下がりで日付が前後する場合あり
- 日付変更は `t_corrected` を使う処理（年月柱・大運・補正後の時）に反映する

## 4. 子時切替モード（確定）

補正後の時・分（`t_corrected`）に対して、時支および日柱用日付を決める。

### 4.1 モード一覧

| モードID | 表示名 | 時支の境界 | 23時台 |
|----------|--------|------------|--------|
| `switch23` | 23時切替 | 23:00–00:59＝子、01:00–02:59＝丑、… | 子時 |
| `switch00` | 0時切替 | 00:00–01:59＝子、02:00–03:59＝丑、…、22:00–23:59＝亥 | 亥時 |

### 4.2 時支インデックス（確定式）

`hour` は `t_corrected` の 0–23。

**23時切替（`switch23`）**

```
hourBranchIndex = floor(((hour + 1) % 24) / 2)
```

**0時切替（`switch00`）**

```
hourBranchIndex = floor(hour / 2)
```

### 4.3 日干（時干算出）と日柱

| モード | 23:00–23:59 の扱い |
|--------|-------------------|
| `switch23` | 時支は子。**日柱日付・時干用日干は翌日**（`resolveDayPillarDate`） |
| `switch00` | 時支は亥。日干・日柱は **当日（`t_corrected` の暦日）** |

0:00–0:59 は両モードとも子時。日柱は `t_corrected` の暦日。

### 4.4 デフォルトと不正値

| 入力 | 扱い |
|------|------|
| 未送信・空 | `switch23` にフォールバック |
| `switch23` / `switch00` | 受理 |
| それ以外の値 | **入力エラー**（計算しない） |

### 4.5 永続化

- 選択は計算のたびにフォーム値を使用
- localStorage 永続化は必須としない

## 5. 計算パイプライン上の位置（日時の分離）

```
入力（年月日・時分・性別・都道府県・時差・子時モード）
  → 入力検証（都道府県コード存在、時差範囲、子時モード契約）
  → t_corrected 算出（時刻がある場合のみ）
  → FortuneCalculator へ t_corrected + shiMode を渡す（時刻なしは入力年月日・時分null）
       ├─ 年柱・月柱: t_corrected で節入り境界判定（時刻なしは入力年月日）
       ├─ 日柱: resolveDayPillarDate(t_corrected, shiMode) の日付
       └─ 時柱: t_corrected の時 + shiMode。時干は日柱日付の日干（時刻なしは時柱なし）
  → GreatFortune:
       ├─ 時刻あり: t_corrected の年月日時分（子時の人工+1日は使わない）
       └─ 時刻なし: 入力年月日の 12:00（V1.0踏襲）
```

### 5.1 影響範囲（確定）

| 対象 | 時刻あり | 時刻なし |
|------|----------|----------|
| 年柱・月柱の節入り | `t_corrected` | 入力年月日（時分なし／既存どおり） |
| 大運立運の節入り距離 | `t_corrected` の epoch 経過（**小数日**。暦日へ丸めない） | **入力年月日 12:00（V1.0踏襲）** からの epoch 経過 |
| 日柱 | `resolveDayPillarDate(...)` の日付 | 入力年月日 |
| 時柱（時支） | `t_corrected.hour` + `shiMode` | なし |
| 時柱（時干） | 日柱日付の日干 | なし |

**禁止:** 子時の人工+1日結果を、年月柱の節入り判定や大運立運に使わない。

## 6. エラー・例外

| ケース | 層 | 挙動 |
|--------|-----|------|
| 時差が許容範囲外（±23:59外） | InputManager | フォームエラー |
| 都道府県コードがマスタに無い | InputManager | フォームエラー |
| 子時モードが定義外 | InputManager | フォームエラー |
| 経度マスタ破損・読込失敗 | サービス/初期化 | 計算/初期化エラー |
| 補正後が対応年範囲外 | Calculator | 既存の節気データ範囲エラーに準拠 |

## 7. 互換性

- 都道府県未選択・時差0・子時モード `switch23`・非23時台なら、時支は V1.0 と同傾向
- V1.5 の `switch23` は **23時台の日柱/時干日跨ぎを明確化**するため、23時台ケースは V1.0 と日柱が異なり得る
- 大運は時分を **経過時間（小数日）** として距離に入れるため、V1.0（正午固定＋暦日差）と開始年齢が異なり得る（仕様変更として受け入れる）
- クリップボード貼り付けは従来パースを維持。新フィールドはフォームで指定
