# 00. 概要とスコープ

## 1. 目的

出生時計時刻を、鑑定に適した基準時刻へ補正し、**時柱**および**節入り境界に依存する年月柱・大運立運**の精度を上げる。あわせて、流派差のある **子時の切替（23時 / 0時）** を選択可能にする。

## 1.1 方法論

本アプリは **四柱推命（子平法ベース）** である。禄命法文書ではない。

## 2. 背景（V1.0 現状）

| 項目 | 現状 |
|------|------|
| 計算基準時 | 日本標準時（JST）前提 |
| 出生時刻 | 任意入力（時・分） |
| 出生地 | 自由テキスト。計算未使用 |
| 海外出生 | 利用者が手動で時差を考慮して入力する運用 |
| 子時 | 23:00–00:59 を子時とする方式（実質23時切替） |
| 大運立運 | 出生日を正午固定で節入り距離を算出 |
| 節気データ | `solar_terms.json`（`+09:00`＝JST） |

## 3. バージョン

| 項目 | 値 |
|------|----|
| バージョン | `1.5.0` |
| ベース | V1.0（タグ `v1.0.0`） |
| 本版の機能追加 | 時刻補正 ＋ 子時切替モード |

## 4. スコープ（In）

1. **地方平均時補正（A）**  
   都道府県選択 → 固定経度マスタ → 明石（東経135°）基準で分補正  
   補正分 = `Math.round(4 × (longitudeEast − 135.0))`
2. **時差補正（C）**  
   標準時からの時差を手入力し、時計時刻を加減算
3. **子時切替モード（D）**  
   - 23時切替  
   - 0時切替  
4. 補正後日時（`t_corrected`）の適用先:
   - **時柱**（子時モード併用）
   - **年柱・月柱の節入り境界**
   - **大運立運の節入り距離（epoch経過の小数日。暦日へ丸めない）**
5. 子時モードによる人工的翌日（`resolveDayPillarDate`）は **日柱・時干のみ**
6. 結果画面および **PNG** への補正情報・子時モード表示
7. 大運API（`calculateStartAge` / 節入り探索）への時分引数追加
8. 関連ドキュメント・テストの更新

## 5. 非スコープ（Out）

- 真太陽時・均時差（Equation of Time）
- 市区町村精度の経度
- 海外地名マスタ / 自動タイムゾーン推定
- 夏時間（DST）の自動適用（必要時は時差手入力で吸収）
- 病薬・その他の新機能
- 禄命法への方式変更

## 6. 関係者前提

- 利用者は「出生地の時計時刻」を入力する
- 補正後の数値日時は **JST暦** として節気データ（`+09:00`）と比較する
- 比較実装は `DateUtils.toJstEpochMillis` と ISO の offset 保持。端末TZに依存しない
- 補正は常時有効だが、入力不足時は不足分の補正のみ行わない
- 時刻が未入力の場合は時柱計算自体を行わない（V1.0踏襲）ため、補正も行わない
- 時刻未入力時の大運は入力年月日 **12:00**（V1.0踏襲）
- 子時モードは時刻入力がある場合に計算へ適用する
