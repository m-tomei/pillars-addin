# 時刻補正機能（V1.5）要件定義

バージョン `1.5` 向けに、出生時刻の補正（地方平均時・時差）と子時切替モードを導入する。

## 方法論の位置づけ（確定）

本機能・本アプリは **四柱推命（子平法ベース）** 向けである。  
禄命法（年柱中心・通変星不使用）の設計対象ではない。既存の日柱・通変星・十二運パイプラインを維持する。

## 確定方針（要約）

- 補正種類: **A 地方平均時** + **C 時差手入力**
- **D**: 夏時間なし / **子時は「23時切替」「0時切替」の2モード**
- 真太陽時（均時差）は **非採用**
- 基準子午線: **東経135°（明石）**
- 地方平均時分: **`Math.round(4 × (longitudeEast − 135.0))`**（東京は **+19分**）
- 日時表現: **JST暦の数値年月日時分**（OSタイムゾーンに依存しない）
- 出生地: **都道府県セレクトのみ**（自由テキスト廃止）
- 時差: 手入力（符号は「出生地時計→JSTへの加算分」が正）。UIは時間+分+符号
- 補正は **常時ON**（条件未充足時は該当分のみスキップ）
- **`t_corrected`**: 年月柱の節入り・大運立運（時分含む）に使用
- **`resolveDayPillarDate` の結果**: 日柱・時干のみに使用（年月柱・大運には使わない）
- 時刻未入力: **補正なし（現状どおり）**。サマリは1行表示。大運は入力年月日 **12:00**
- 本バージョンの機能追加は **時刻補正＋子時モード** のみ
- バージョン表記: **`1.5.0`**
