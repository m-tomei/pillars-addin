## 2. 処理ステップ（疑似コード）

```text
function diagnose(input):
  dayElement = STEM_ELEMENTS[fortune.dayPillar.stem]
  transformedMap = gouChuu?.transformedElementMap

  // S1. 五行分布（月令ブースト付き）
  dist = calcElementDistribution(fortune, transformedMap, pillarWeights)

  // S2. 從重者論
  heaviest = findHeaviestElement(dist)          // 必ず後段で使用
  heaviestRatio = dist[heaviest] / sum(dist)

  // S3. 四病分類（從重・身旺弱・主軸を入力）
  fourDisease = classifyFourDisease(...)

  // S4. 四薬分類
  fourMedicine = classifyFourMedicine(fourDisease, ...)

  // S5. 継善 breaks → 格局ルール照合 → 具体診断
  specific = matchRulesByBreaks(keizen.breaks, kakkyoku, strength)
  if specific empty: specific = [defaultDisease]

  // S6. 気象病の併記
  if kishou.isExtreme:
    append kishouDisease/Medicine as secondary diagnosis
      （既に同趣旨があればマージ）

  // S7. 各診断の薬を調候と突合
  for each diag:
    diag.medicine = reconcileMedicine(diag.medicine, kishou.choukou, dayElement)
    diag.medicine.location = findInChart(...)
    diag.disease.element = consistentElement(diag)  // 病名と一致させる

  // S8. 病力・薬力・バランス
  balance = assessBalance(diagnoses, dist, kishou, fortune)

  // S9. 喜忌ラベル
  kiki = { ki: medicines..., ki_gods..., ji: diseases... }

  representative = first primary keizen diagnosis
                   ?? first diagnosis

  return ByoyakuResult {
    disease: representative.disease,
    medicine: representative.medicine,
    diagnoses, ..., heaviestElement, kishou, keizen, balance, kiki
  }
```

`diagnoses` は表示順、`disease` / `medicine` は後方互換の代表値であり、同じ先頭要素とは限らない。

## 3. 從重者論（月令ブースト）

### 3.1 分布

- 基本加重: 天干1.0 / 蔵干主0.7 / 中0.5 / 余0.3  
- **月支蔵干主気に ×2.0**（または +1.0。02参照）  
- 合化成功支は化後五行を主気相当で加算  

### 3.2 最重五行の利用

| 条件 | 四病への接続 |
|------|--------------|
| heaviestRatio ≥ 0.40 | 旺の病候補。diseaseElement = heaviest |
| heaviest が用神を剋／奪う関係 | breaks が空でも病候補に昇格検討 |
| それ以外 | fourDisease の他判定へ |

**現行バグ修正:** `heaviestElement` を計算して捨てない。

## 4. 四病分類（優先順）

優先順は維持しつつ、入力を強化する。

```text
1. 特殊格局（五行一気・従格）→ 旺/弱
2. 雕 … 用神あり＆対立カテゴリが透蔵ともに無い
3. 枯 … 用神弱＆天干に無く＆蔵干に根あり
4. 旺 … 從重比率≥40% or 身旺スコア高
5. 弱 … デフォルト（身弱 or 用神弱）
```

### 4.1 雕と気象の関係

- `fourDisease` は `雕|枯|旺|弱` 以外へ拡張しない
- 気象が extreme かつ `heaviestRatio >= 0.40` なら、雕チェックより先に `旺` を確定する
- それ以外の気象偏りは `source='kishou'` の副診断として表し、四病分類へ「気象」という独自値を入れない
- 用神損傷がなく気象偏りだけが severe の場合は、気象診断を表示上の先頭へ昇格できる

**レビュー項目 B-1:** extreme 気象時の四病優先。

## 5. 四薬分類

> **P0未確定:** 提供資料は四病四薬の名称と次章への接続までは確認できるが、四処方それぞれの詳細判定例を収録していない。下表は現行実装を整理した暫定案であり、R-01の資料追補・専門レビュー完了前に確定仕様として実装しない。

| 四病 | 四薬 | 五行の取り方 |
|------|------|--------------|
| 旺 | 損 | 病五行を剋する五行（または洩） |
| 弱 | 益 | 病五行を生じる／同類 |
| 枯 | 生（暫定） | 用神を生じる五行 |
| 雕 | 損（磨く） | 対立カテゴリの五行 |

- `長` の発動条件は未定義。根拠なしに `生` と同義扱いしない。
- R-01で `生` と `長` の境界、代表例、反例を決定する。
- 最終的な表示薬は S7 の突合結果を優先し、四薬は理論分類ラベルとして残す。

## 7. 調候 × 十神薬の突合（核心）

```text
function reconcileMedicine(tenGodMedicine, choukou, dayElement):
  tenGodEls = [element of tenGodMedicine]
  choukouEls = choukou.primaryElements

  intersection = tenGodEls ∩ choukouEls
  if intersection not empty:
    return {
      name: tenGodMedicine.name,
      element: intersection[0],
      tenGod: tenGodMedicine.tenGod,
      choukouAligned: true,
      note: '格局薬と調候が一致'
    }

  if choukou.direction == 'なし':
    return tenGodMedicine (+ choukouAligned: false)

  # 不一致: 主薬＝十神薬、副薬＝調候
  return {
    primary: tenGodMedicine,
    secondary: {
      name: `調候（${choukou.direction}）`,
      elements: choukouEls,
      tenGod: null
    },
    choukouAligned: false,
    note: '主軸の薬と調候を併記'
  }
```

表示時は primary/secondary を薬ブロック2段、または1段＋注記で出す。

## 8. 病薬バランス

### 8.1 病力スコア（0〜3）

| 条件 | 加点 |
|------|------|
| severity=severe | +2 |
| severity=moderate | +1 |
| 病が月令を得る | +1 |
| 病五行が天干2つ以上 | +1 |
| 病に蔵干本気の根 | +1 |
| 上限 | 3 |

### 8.2 薬力スコア（0〜3）

| 条件 | 加点 |
|------|------|
| 命式内に薬あり（天干） | +2 |
| 命式内に薬あり（蔵干のみ） | +1 |
| 薬が月令を得る | +1 |
| 調候一致 | +1 |
| 上限 | 3 |

### 8.3 ラベル

| 病力 | 薬力 | balance |
|------|------|---------|
| ≥2 | ≥2 | 病重薬重 |
| ≥2 | ≤1 | 病重薬軽 |
| ≤1 | ≥2 | 病軽薬重 |
| ≤1 | ≤1 | 病軽薬軽 |
| 病なし扱い | 薬なし | 病なし薬なし |

`病なし薬なし` は雕または breaks空＆気象非extreme＆中和に近いとき。
