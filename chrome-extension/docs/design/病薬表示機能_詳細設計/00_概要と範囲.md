## 1. 目的

命理正宗に基づき、命式の **病** と **薬** を算出し、ユーザーが判断の中心として使える形で表示する。

本機能はアドイン上の最重要機能であり、命式算出（F-01）の上にオプションとして載るが、**設計・品質の優先度は病薬側を最上位**とする。

## 2. 一言定義

```text
病 = 命式中で害をなしている神（および気象の偏枯）
薬 = その害を除き、主軸（用神）を守る／調候する五行・十神
```

## 5. 設計原則

1. **順序厳守** — 気象・主軸なしに病薬名だけ出さない  
2. **活法** — 同じ十神でも気象・主軸で意味が変わる  
3. **説明可能性** — なぜその病／薬かを reason と根拠フィールドで残す  
4. **複数病許容** — 主病＋副病（気象病など）を配列で返す  
5. **既存資産活用** — `ByoyakuCalculator` / `kakkyoku_rules.json` を拡張して使う  

## 6. 成功条件（詳細設計レビュー通過の定義）

- 理論マッピングに抜けがないとレビューアが判断できる  
- アルゴリズムが疑似コード／判定表まで落ちている  
- 入出力スキーマが実装可能な粒度である  
- テストシナリオで資料の代表例を検証できる  
- 未決事項が明示され、レビューで決められる  

## 7. 用語

| 用語 | 意味 |
|------|------|
| 主軸 | 継善篇的に守るべき柱。本実装では格局由来の用神カテゴリ |
| 用神損傷（破） | 主軸を壊す要素 |
| 気象 | 寒暖・燥湿・（清濁）の局全体の空気 |
| 調候 | 気象の偏りを整える方向（温める／冷ます／潤す等） |
| 從重者論 | 重い勢力から論じる病薬説の下手法 |
| 喜／忌 | 病薬確定後の粗いラベル（薬側＝喜、病側＝忌） |
