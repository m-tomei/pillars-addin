# 07. UI詳細設計（病薬セクション）

| 文書ID | BYO-DD-07 |
|--------|-----------|

## 1. 表示条件

- 病薬オプションONかつ `byoyakuResult` あり → 表示  
- OFF → セクション非表示・中身クリア  

## 2. セクション構成（上から順）

```text
┌─────────────────────────────────────┐
│ 病薬診断                             │
├─────────────────────────────────────┤
│ ① 気象                              │
│ ② 主軸（継善）                       │
│ ③ 身旺弱（補助・1行）                 │
│ ④ 病 / 薬（diagnoses ごと）          │
│ ⑤ 病薬バランス                       │
│ ⑥ 喜忌（任意・折りたたみ可）          │
└─────────────────────────────────────┘
```

## 3. 各ブロック仕様

### ① 気象

| 項目 | 表示例 |
|------|--------|
| タイトル | 【気象】寒・湿（偏り: 中度） |
| 本文 | 調候: 温める → 火（木） |
| summary | `kishou.summary` |

extreme でない場合も一行は出す（「気象: 中和」）。

### ② 主軸

| 項目 | 表示例 |
|------|--------|
| タイトル | 【主軸】正官格（官殺を守る） |
| 状態 | 成格 / 破格（理由） |
| 損傷 | 破: 傷官見官 …（breaks要約。なければ「目立った破なし」） |

### ③ 身旺弱

現行どおりスコア付き1行。色分け維持可。

### ④ 病／薬

各 `DiagnosisItem`:

```text
【病1・主】比劫奪財（旺の病・中度）
  五行: 木 ／ 十神: 比肩

【薬】官殺（損の薬）→ 金
  理由: …
  ✓ 命式中に薬あり（時干）
  （調候一致 / 調候併記）

【薬・調候】温める → 火   ← medicineSecondary があるとき
```

- `role=secondary` は「病2・副（気象）」などと明示  
- 複数 diagnoses は番号付き  

### ⑤ バランス

| label | 表示文例 |
|-------|----------|
| 病重薬重 | 病も薬も重い。行運で中和を取りやすい型 |
| 病重薬軽 | 今は薬不足。薬旺の運を待つ |
| 病軽薬重 | 薬が勝ちすぎて別偏りに注意 |
| 病軽薬軽 | 小さな不均衡 |
| 病なし薬なし | 平常に近く、大きな起伏が出にくい |

### ⑥ 喜忌（任意）

```text
喜: 官殺・火（調候）
忌: 比肩
```

初版は出すことを推奨（短く）。

## 4. 非表示・削除

| 現行 | 本設計 |
|------|--------|
| 「格局・病薬 診断」紫ヘッダ一体 | 「病薬診断」に改名。格局は主軸行へ |
| 結果内 `#kakkyoku-toggle` | 廃止（計算前オプションへ） |

## 5. 空・エラー

| 状態 | UI |
|------|----|
| 診断0件（理論上稀） | 「病薬を特定できませんでした」 |
| diagnose 例外 | 赤字で失敗メッセージ。命式は残す |
| 気象フォールバック | 「気象: 判定簡易（中和扱い）」 |

## 6. PNG保存

病薬ON時は本セクションをキャプチャ範囲に含める。
