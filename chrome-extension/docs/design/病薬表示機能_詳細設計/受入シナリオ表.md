## 1. 使い方

- 手動受入と自動テストは同じ入力を使う
- 期待四柱は FortuneCalculator の出力を正とする
- 「五行偏重」と「主軸病薬」は別レイヤーとして確認する
- 画面が期待どおりでも仕様・テスト条件が不整合なら完了にしない

機械可読版（v1.2同期済）: [fixtures/acceptance_scenarios.json](./fixtures/acceptance_scenarios.json)

## 4. 固定ルール

1. 入力のタイムゾーンはJST（既存エンジン前提）
2. 節気境界から5日未満の日付は採用しない（例外時は表に明記）
3. 期待四柱がFortuneCalculatorと食い違う場合はエンジン側を調査し、表だけを直さない
4. 性別は大運表示確認用。病薬本体の四病四薬には原則影響しない
5. 五行偏重の四病四薬と主軸病薬が衝突する場合、両方を喜として併記せず突合規則を確認する
