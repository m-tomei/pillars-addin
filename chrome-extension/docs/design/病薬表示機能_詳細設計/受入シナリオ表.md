## 1. 使い方

- 手動受入と自動テストは**同じ入力**を使う  
- 期待四柱は FortuneCalculator の出力を正とする  
- 病薬の期待値は「現行エンジン」列を回帰用に固定する  
- R-01実装後に変わる項目は「実装後期待」列で示す  

機械可読版: [`fixtures/acceptance_scenarios.json`](./fixtures/acceptance_scenarios.json)

## 4. 固定ルール

1. 入力のタイムゾーンは JST（既存エンジン前提）  
2. 節気境界から5日未満の日付は採用しない（例外時は表に明記）  
3. 期待四柱が FortuneCalculator と食い違う場合は**エンジン側を調査**し、安易に表だけ直さない  
4. 性別は大運表示確認用。病薬本体の四病四薬には原則影響しない
