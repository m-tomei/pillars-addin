## 1. 四篇の役割分担

| 篇 | 資料上の役割 | 本機能での実装責務 |
|----|--------------|-------------------|
| 喜忌篇 | 看命の順序・日干為主・月令提綱 | パイプライン順序、柱ウェイト、最終喜忌ラベル |
| 気象篇 | 先に局の空気を見る | `KishouAssessor`、調候方向 |
| 継善篇 | 主軸を立て壊すものを探す | 主軸確定、`breaks[]`（用神損傷） |
| 病薬説 | 病と薬を具体化する | 從重・四病四薬・格局別診断・バランス |

## 2. 資料要件 → 設計要素対応表

### 2.1 喜忌篇

| 資料要件 | 設計要素 | 必須 |
|----------|----------|------|
| 日上天元を主とする | `dayStem` / `dayElement` を全判定の基準 | ○ |
| 月を提綱とする | 月令ブースト、気象の起点 | ○ |
| 年基根・月提綱・日命主・時分野 | 五行加重の柱係数 | ○ |
| 透干と蔵干を分ける | 透干ウェイト＞蔵干 | ○ |
| 喜忌は役割で決まる | 病→忌、薬→喜（確定後ラベル） | ○ |
| 神殺は最後 | 初版非実装 | − |

### 2.2 気象篇

| 資料要件 | 設計要素 | 必須 |
|----------|----------|------|
| 先に気象規模、後に用神 | 気象を病薬より前に実行 | ○ |
| 寒暖 | `temperature`: 寒/涼/温/熱 | ○ |
| 燥湿 | `humidity`: 燥/中/湿 | ○ |
| 清濁 | `clarity`: 初版は `不明` 固定 | −（後続仕様） |
| 好悪は一律でない | 調候方向で薬を補正 | ○ |
| 偏枯＝大きな病の空気 | `kishouDisease` 候補 | ○ |

### 2.3 継善篇

| 資料要件 | 設計要素 | 必須 |
|----------|----------|------|
| 用神を損傷してはならない | `breaks[]` 検出 | ○ |
| 格局の柱を守る | `pillar.youshinCategory` | ○ |
| 日主健旺が望ましい | 身旺弱を入力として利用 | ○ |
| 破があれば病 | breaks → 病候補 | ○ |
| 有官有印無破等 | 条件付きの成立フラグ（補助） | △ |

### 2.4 病薬説

| 資料要件 | 設計要素 | 必須 |
|----------|----------|------|
| 主軸→病→薬の基本対応 | 格局ルール＋損傷表 | ○ |
| 從重者論 | 月令起点の最重五行 | ○ |
| 四病・四薬 | 分類エンジン | △（名称は確認済み。詳細判定、とくに「長」はR-01で根拠追補が必要） |
| 病薬の強弱バランス | `balance` ラベル | ○ |
| 薬の所在 | `medicine.exists/location` | ○ |
| 複数病 | `diagnoses[]` | ○ |
| 病なし薬なし＝平常／雕へ接続 | 雕判定＋平常フラグ | ○ |

## 3. 必須の看命順序（契約）

資料を統合した本機能の正規順序:

```text
① 日干確定          … 喜忌
② 月令確定          … 喜忌
③ 気象評価          … 気象
④ 透干/蔵干整理     … 喜忌
⑤ 格局・主軸確定    … 継善（格局計算を利用）
⑥ 用神損傷列挙      … 継善
⑦ 從重者論          … 病薬
⑧ 四病・四薬        … 病薬
⑨ 格局別具体病薬    … 病薬
⑩ 調候と十神薬の突合 … 気象×病薬
⑪ 病薬バランス      … 病薬
⑫ 喜忌ラベル付与    … 喜忌
```

**決定:** この順序で固定する。`KishouAssessor` の結果を先に確定し、後段の病薬処方が必ず参照する。

## 5. 理論上の優先ルール（矛盾時）

| 優先度 | ソース | 扱い |
|--------|--------|------|
| 1 | 継善・用神損傷 | **主病**候補 |
| 2 | 気象・調候偏枯 | **副病**候補（用神損傷がなく severe の場合のみ表示上の先頭へ昇格可） |
| 3 | 從重の過旺五行 | 旺の病として接続 |
| 4 | 格局 defaultDisease | 上記が空のときのフォールバック |

薬の突合:

```text
十神薬 ∩ 調候方向 が空でない → その交差を優先
交差が空 → 主病の十神薬を主薬、調候を副薬として併記
```
