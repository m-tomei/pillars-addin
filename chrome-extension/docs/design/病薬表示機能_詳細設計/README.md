## レビュー依頼事項

1. 理論順（喜忌→気象→継善→病薬）でよいか  
2. 気象と用神損傷が矛盾したときの優先（推奨: 損傷優先＋気象を副病）でよいか  
3. 初版で清濁まで入れるか（推奨: 寒暖・燥湿のみ）  
4. UIに気象・主軸・病薬バランスをどこまで出すか
