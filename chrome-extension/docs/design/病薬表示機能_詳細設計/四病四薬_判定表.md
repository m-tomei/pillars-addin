## 1. 結論サマリ（実装向け）

| 四病 | 意味（要約） | 対応四薬 | 薬の取り方（要約） |
|------|--------------|----------|-------------------|
| 雕 | 用神が純で対立がなく、磨かれていない | **琢**（対立導入）※1 | 用神の対立十神カテゴリの五行 |
| 枯 | 財官印等に**根はあるが気枯れ** | **生** | 対象を生じる五行（滋養） |
| 旺 | 五行・十神の**有余** | **損** | 有余を剋／洩して削る |
| 弱 | 五行・十神の**不及**（根あることが望ましい） | **益** | 生じる／同類で補う |

| 四薬 | 発動の核心 | 喜ぶ運行の方向 |
|------|------------|----------------|
| 損 | 有余を削る | 剋・洩の運 |
| 益 | 不及を補う | 生扶・同類の運 |
| 生 | **長生段階**（気は芽生え、まだ旺と言えない） | 滋養・通関の運 |
| 長 | **帝旺・長養段階**（気は方敷・方熾） | **克の運**（生扶ではない） |

※1 原文の四薬は「損・益・生・長」の四字。雕に対する「琢」は、対立要素で磨く働きを実装ラベルとして明示したもの。APIでは `fourMedicine: '琢'` を許容する（後方互換で旧実装の `損` は雕に使わない）。

## 2. 四病（雕枯旺弱）

### 2.1 雕

**原文要旨:**  
玉も金も、彫琢・鍛錬があってこそ用をなす。八字で官に傷官なく、財に比劫なく、印に財なく、食傷に印なければ、未琢の玉・未煉の金に等しい。ゆえに「貴有雕」。

| 項目 | 判定 |
|------|------|
| 条件 | 用神カテゴリが天干に存在する AND 対立カテゴリが透干・蔵干ともに無い |
| 対立 | 官殺↔食傷、財↔比劫、印↔財、食傷↔印 |
| diseaseElement | 用神の五行（害神というより「磨き不足の対象」） |
| 代表例 | 正官格で傷官も食神も蔵干に無い |
| 反例 | 官透出だが時支に傷官蔵干あり → 雕ではない |

### 2.2 枯

**原文要旨:**  
官・財は「枯」を貴ぶが、**根があって枯れている**ことが肝要。無根の枯れは貴ばない。「根在苗先」。

| 項目 | 判定 |
|------|------|
| 条件 | 用神五行が天干に透出せず、分布が弱い AND 蔵干に同五行の根がある |
| diseaseElement | 用神の五行 |
| 代表例 | 財格だが財が蔵干余気のみで天干に無し |
| 反例 | 用神が天干に全く無く蔵干にも根なし → 枯ではなく弱／無依 |

### 2.3 旺

**原文要旨:**  
各五行が質を全うして過旺する。印太旺は財運で破り、日主太旺は官殺で制す、など有余を削る。

| 項目 | 判定 |
|------|------|
| 条件 | 從重最重五行の比率 ≥ 閾値（暫定0.40・R-02） OR 身旺スコア高 |
| diseaseElement | 過旺している五行 |
| 代表例 | 比劫が天干に重なり月令も同気 |
| 反例 | やや身旺だが從重が分散 → 旺にしない |

### 2.4 弱

**原文要旨:**  
雨露不足・血気不充。財官印・日主の弱は、旺地へ行けば起こしうる。ただし**極弱無根を畏れる**。

| 項目 | 判定 |
|------|------|
| 条件 | 雕・枯・旺に該当せず、日主または用神が不足 |
| diseaseElement | 不足側（日主優先、次に用神） |
| 代表例 | 身弱で官殺が重い |
| 反例 | 弱に見えても根が深く從重が別五行 → 別病を優先 |

### 2.5 判定優先順（実装）

```text
1. 特殊格局（専旺／従格）→ 旺 or 弱
2. 雕
3. 枯
4. 旺（從重・身旺）
5. 弱（デフォルト）
```

気象偏枯は四病enumに入れず、別診断（`source: kishou`）とする（PR#10決定済み）。

## 3. 四薬（損益生長）— とくに生と長

### 3.1 損

> 損者，損其有余也。

| 項目 | 内容 |
|------|------|
| 対象病 | 主に **旺** |
| 薬五行 | 有余五行を剋する五行（格局により洩も可） |
| 例 | 土多 → 木で疎通／剋。金有余 → 火で剋 |

### 3.2 益

> 益者，益其不及也。

| 項目 | 内容 |
|------|------|
| 対象病 | 主に **弱** |
| 薬五行 | 不及を生じる五行、または同類 |
| 例 | 木不及 → 水で根本を滋す／木運で枝葉を茂らす |

### 3.3 生（ここが長と分かれる）

> 生者長初……形気始分、赤子未離於褓。木之生於亥、根気猶枯也、未可以木為旺也。

| 項目 | 内容 |
|------|------|
| 意味 | **長生段階**の気。芽生えで、まだ旺と言えない。だから滋養する |
| 陰陽注意 | 六陽の長生は真の生（甲木亥）。六陰の「長生」は弱に傾く場合あり（乙木午など）。六陰の死処が反って生となる場合あり |
| 対象病 | 主に **枯**。また財官印が生地にあって気不足のとき |
| 薬の方向 | 対象を生じる五行で根本を養う（例: 木←水） |
| 代表例 | 甲木が亥にあり根気なお枯 → 水の滋養が生の薬 |
| 反例 | 木がすでに寅卯辰で方敷 → 生ではなく **長** |

### 3.4 長（R-01の核心）

> 長者生之継也。……帝旺之郷、実不同於生長之位。……財官属木、則長養在寅卯辰之方……貴行金運以克之、則与長生之木理不同也。

| 項目 | 内容 |
|------|------|
| 意味 | **帝旺・長養**まで進んだ気。方敷・方熾であり、生扶ではなく **克** が薬 |
| 長養の目安（対象五行） | 木: 寅卯辰／火: 巳午未／金: 申酉戌／水: 亥子丑／土: 四季・火土の旺地（簡易は月支季節） |
| 対象病 | 対象（用神・財官印・從重の主役）が長養・帝旺にあり過敷のとき。旺病と重なりやすい |
| 薬の方向 | 対象を剋する五行の運（木の長 → 金運、火の長 → 水運） |
| 生との差 | 生=喜生扶、長=喜克 |
| 代表例 | 財官が木で寅卯辰に長養 → 金運で克るのが長の薬 |
| 反例 | 同じ木でも亥の長生 → 金で克るのは長ではなく、まず生（水滋）を優先 |

### 3.5 生／長の機械判定（初版）

対象五行 `E`（用神五行、または從重の病五行）について:

```text
stage = 月支からみた E の勢い段階
  - E の長養三方（上記）に月支が含まれる → '長養'
  - E の長生支が月支、または十二運が長生／沐浴 → '長生'
  - それ以外 → 'その他'

if fourDisease == '枯':
    fourMedicine = '生'
    medicineElement = E を生じる五行
else if fourDisease == '旺' and stage == '長養':
    fourMedicine = '長'          # 帝旺的過敷は克で抑える
    medicineElement = E を剋する五行
else if fourDisease == '旺':
    fourMedicine = '損'
    medicineElement = E を剋する五行（洩は格局ルール側）
else if fourDisease == '弱':
    fourMedicine = '益'
    medicineElement = E を生じる五行 or 同類
else if fourDisease == '雕':
    fourMedicine = '琢'
    medicineElement = 対立カテゴリの五行
else if stage == '長生' and E が用神で気不足:
    fourMedicine = '生'
    ...
```

**注:** 旺かつ長養のとき `長` を優先する。剋という作用は損と近いが、**ラベルを長にすることで「生扶してはいけない」ことが明示される**（原文: 喜生喜克之異）。

## 4. 病→薬 対応表（確定案）

| 四病 | 四薬 | medicineElement | 備考 |
|------|------|-----------------|------|
| 旺（長養） | 長 | 病五行を剋する五行 | 生扶禁止を明示 |
| 旺（その他） | 損 | 病五行を剋／洩 | 格局別で洩を選びうる |
| 弱 | 益 | 生元または同類 | |
| 枯 | 生 | 用神を生じる五行 | 無根なら枯としない |
| 雕 | 琢 | 対立カテゴリ五行 | enum追加 |

格局別の具体病薬名（`kakkyoku_rules.json`）は、上記四薬ラベルの**上に乗る具体処方**として維持する。
