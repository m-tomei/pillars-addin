# 04. 継善・用神損傷詳細（KeizenAnalyzer）

| 文書ID | BYO-DD-04 |
|--------|-----------|
| 根拠 | `資料/継善篇_初心者から中級者向け解説.md` |

## 1. 目的

格局から **守るべき主軸（柱）** を定め、それを壊す要素（用神損傷＝破）を列挙する。  
病薬説へ渡す「主病候補」の入力を作る。

## 2. 公開API

```text
KeizenAnalyzer.analyze(
  kakkyokuResult,
  strengthResult,
  tsuuhenResult,
  fortuneResult,
  conditions?   // Byoyaku側と共用してもよい
) → KeizenResult

KeizenResult {
  pillar: {
    kakkyoku: string
    youshinCategory: 'officer'|'wealth'|'output'|'seal'|'self'|null
    youshinLabel: string          // 例: 正官 / 財 / 食傷
    youshinElement: string|null
    isEstablished: boolean
  }
  breaks: BreakItem[]             // 損傷リスト（0件以上）
  supports: SupportItem[]         // 柱を助ける要素（表示・説明用）
  summary: string
}

BreakItem {
  id: string                      // 例: 'shokkan_see_kan'
  condition: string               // kakkyoku_rules の condition 名と揃える
  name: string                    // 例: 傷官見官
  diseaseTenGod: string|null
  diseaseElement: string|null
  severityHint: 'mild'|'moderate'|'severe'
  reason: string
}

SupportItem {
  name: string
  tenGod: string|null
  reason: string
}
```

## 3. 主軸（pillar）の決定

既存マップを正式仕様として採用:

| 格局 | youshinCategory | youshinLabel |
|------|-----------------|--------------|
| 正官格 / 偏官格 | officer | 官殺 |
| 正財格 / 偏財格 | wealth | 財 |
| 傷官格 / 食神格 | output | 食傷 |
| 印綬格 / 偏印格 | seal | 印 |
| 建禄格 / 陽刃格 | self | 比劫（身旺→財官を求める） |
| 五行一気・従格等 | 特例 | 身旺弱に応じ別扱い |

`youshinElement` は日干基準の五行変換（既存 `_getCategoryElement` と同定義）。

## 5. supports（助け）の扱い

初版は表示用の参考に留め、病薬確定ロジックの必須入力にはしない。

例（正官格）:

- 財が官を生じる → support  
- 印が身を助け官を受ける → support  

## 6. `kakkyoku_rules.json` との関係

```text
Keizen.breaks[].condition
    ↓ 照合キー
kakkyoku_rules[格局][strong|weak].diseases[].condition
```

- breaks に載った condition を **先に** ルールへマッチ  
- breaks が空 → `defaultDisease`  
- ルールに無い break は、BreakItem の name/reason で診断を直接生成（フォールバック）

中和身（neutral）の扱い:

```text
strength === 'neutral' → 当面 'strong' 側ルールを試し、
マッチゼロなら 'weak' 側 default を検討
（レビュー項目 KZ-1）
```

## 7. 継善の成果が病薬に渡る形

```text
主病候補 = breaks（severityHint 降順）
主軸情報 = pillar
成格フラグ = pillar.isEstablished（破格なら severity 底上げ）
```

## 8. 資料実例との対応

### 正官格（甲・酉月・辛透・癸印・戊財）

| 項目 | 期待 |
|------|------|
| pillar | 官殺 |
| breaks | 傷官が無ければ空、または軽微 |
| supports | 財生官、印護身 |

### 印綬格で財が強い

| 項目 | 期待 |
|------|------|
| pillar | 印 |
| breaks | 貪財壊印 |

### 財格で比劫多

| 項目 | 期待 |
|------|------|
| pillar | 財 |
| breaks | 比劫奪財 |
| 薬方向 | 官殺 |
