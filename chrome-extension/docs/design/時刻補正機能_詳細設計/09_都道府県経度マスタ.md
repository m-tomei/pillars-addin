# 09. 都道府県経度マスタ

## 1. 規則

| 項目 | 値 |
|------|-----|
| 基準子午線 | 東経 135.0°（明石） |
| 代表点 | 都道府県庁所在地 |
| 単位 | 東経・度（小数点以下4桁目を目安） |
| 補正分 | `Math.round(4 * (lon - 135))`（東京は **+19分**） |
| コード | 都道府県コード 2桁（文字列） |
| スキーマ | 詳細設計 `05` / 要件 `03` の正式スキーマ（`version`, `referenceName`, `longitudeUnit`, `sourceNote`） |
| 件数 | 47件必須 |
| 配置 | `chrome-extension/data/prefecture_longitude.json`（確定） |

実装時の JSON 値は下表を初期値とする。出典メモを JSON の `sourceNote` に記載する。

## 3. ファイル生成

実装タスクで上表を `prefecture_longitude.json` に落とし込む。  
経度の微修正が必要な場合は本表と JSON を同時更新する。

## 4. ルックアップ

```js
const map = new Map(master.prefectures.map(p => [p.code, p]));
const pref = map.get(code);
if (!pref) throw ...
```

名称表示は常にマスタの `name` を使う（UIハードコードと漂移させない）。
