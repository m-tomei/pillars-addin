## 設計方針（要約）

1. 補正計算は新規モジュール `TimeCorrectionService` に集約する
2. `FortuneCalculator` は **補正済み日時＋shiMode** を受け取る
3. `GreatFortuneCalculator` は **時分引数を追加**し、`t_corrected` の時分まで立運に反映する
4. 子時の人工+1日は `resolveDayPillarDate` により **日柱・時干のみ**。年月柱・大運には使わない
5. 日時は JST暦の数値演算（OS TZ非依存）。丸めは `Math.round`
6. UIは都道府県・時差・子時モードを追加し、結果DOMに補正サマリを載せてPNGへ含める
