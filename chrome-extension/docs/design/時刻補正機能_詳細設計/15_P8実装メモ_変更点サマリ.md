# V1.5 時刻補正 実装メモ（変更点サマリ）

実施日: 2026-08-13
対象版: **1.5.0**（ベース `v1.0.0`）
方法論: 四柱推命（子平法）。禄命法化はしていない。

## 1. 何が変わったか

入力時刻に、時差と地方平均時補正を加えた `t_corrected` を命式・大運の基準にした。

```
t_corrected = 入力時刻 + 時差 + round(4 × (経度 − 135))
```

- 基準子午線は明石・東経135°。東京都は **+19分**。
- 真太陽時は使わない。夏時間は時差へ手入力。
- 日時は JST 数値暦。OSローカル `new Date(y, m-1, ...)` は使わない。

## 3. V1.0 との差分（意図的）

| ケース | V1.0 | V1.5 |
|--------|------|------|
| 都道府県なし・時差0・非23時台・`switch23` | 既存結果 | **同結果を維持** |
| 23時台・`switch23` | 日柱＝暦日、時支＝子 | 日柱＝翌日、時支＝子 |
| `switch00`・23時台 | （なし） | 時支＝亥、日柱＝当日 |
| 大運 | 正午固定＋暦日差 | 補正後時分の小数日。時刻なしは入力年月日 12:00 |

`resolveDayPillarDate` の翌日送りは **日柱と時干だけ**。年柱・月柱・大運には使わない。
