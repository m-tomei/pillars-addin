# 01. 現状分析と変更点

## 1. V1.0 現状

| 領域 | 現状 |
|------|------|
| 出生時刻 | 任意。`hour`/`minute` をそのまま計算へ |
| 出生地 | 自由テキスト。計算・結果未使用 |
| 時差 | なし |
| 時柱 | `(hour+1)%24/2` で時支。23時＝子 |
| 日柱 | 暦日。23時台でも日は変わらない |
| 節入り | 入力日時を JST 相当として比較 |
| 大運 | `calculateStartAge` / 節探索が **正午固定**（時分未使用） |
| PNG | 補正情報なし |
| 方法論 | 四柱推命（日柱・通変・十二運あり） |

## 2. 主要変更点

| ID | 変更 | 影響ファイル（主） |
|----|------|-------------------|
| C1 | 出生地を都道府県セレクトへ置換 | `sidepanel.html`, `FormRenderer`, `InputParser` |
| C2 | 時差入力追加 | 同上, `InputManager` |
| C3 | 子時モード追加 | 同上, `FortuneCalculator` |
| C4 | 補正サービス新設 | `TimeCorrectionService.js`, `DataLoader` |
| C5 | AppController が補正後に計算 | `AppController.js` |
| C6 | `resolveDayPillarDate` による23時切替の日柱日跨ぎ | `FortuneCalculator` |
| C7 | 結果サマリ＋PNG | `ResultRenderer`, CSS |
| C8 | 大運APIに時分追加 | `GreatFortuneCalculator.js` |
| C9 | バージョン 1.5.0 | `package.json`, footer, docs |

## 3. 互換性・破壊的変更

| ケース | V1.0 | V1.5 |
|--------|------|------|
| 都道府県なし・時差0・非23時台・`switch23` | — | 同結果を維持 |
| 23時台・`switch23` | 日柱＝暦日、時支＝子 | 日柱＝翌日、時支＝子 |
| `switch00`・23時台 | （なし） | 時支＝亥、日柱＝当日 |
| 節入り近傍の大運 | 正午基準 | **補正後時分**基準（異なり得る） |

## 4. 現状コードの着目点

- `FortuneCalculator.calculateHourPillar`: 実質 `switch23` の時支式
- `calculateDayPillar`: 23時台でも日跨ぎなし
- `GreatFortuneCalculator.calculateStartAge` / `_getNextSolarTerm` / `_getPreviousSolarTerm`: 常に 12:00
- `birthplace` は計算未使用
