# 06. UI詳細設計

## 1. 入力フォーム配置順（確定）

1. 生年月日  
2. 出生時刻  
3. 子時の切替  
4. 性別  
5. 出生地（都道府県）  
6. 標準時からの時差  
7. ボタン群  

### 1.1 出生地

- `<select id="prefecture">`（未選択＋マスタから47件）
- 自由テキスト廃止

### 1.2 時差

```html
<select id="tz-sign"><option value="+">+</option><option value="-">-</option></select>
<input type="number" id="tz-hour" min="0" max="23" value="0">
<input type="number" id="tz-minute" min="0" max="59" value="0">
```

### 1.3 子時モード

```html
<input type="radio" name="shi-mode" value="switch23" checked>
<input type="radio" name="shi-mode" value="switch00">
```

ヘルプ文は選択に応じて切替（**必須**。P4実装）。

- 時差ヘルプ: `日本国内のみの場合は 0 のままで構いません。海外出生は、出生地の時計時刻を日本標準時へ合わせる差を入力します。夏時間は手動で時差に含めてください。`
- 子時 23時切替: `23:00〜0:59を子時。23時台は翌日の日柱として扱います`
- 子時 0時切替: `0:00〜1:59を子時。23時台は亥時・当日の日柱です`

## 3. 結果サマリ（確定）

命式テーブル直前に `#time-correction-summary`。

### 時刻あり（`applied: true`）

```html
<section class="correction-summary" id="time-correction-summary">
  <h3>時刻補正</h3>
  <p>時刻補正: 適用</p>
  <ul>
    <li>入力時刻: …</li>
    <li>時差: …</li>
    <li>地方平均時補正: …</li>
    <li>補正後時刻: …</li>
    <li>子時モード: …</li>
  </ul>
  <!-- switch23かつ23時台なら注記 -->
</section>
```

補正量0でも内訳を出す。

### 時刻なし（確定）

```html
<section class="correction-summary" id="time-correction-summary">
  <p>時刻補正: 時刻未入力のため補正・時柱なし</p>
</section>
```

### clear()

`#time-correction-summary` を空にして非表示にする。命式・大運DOMも既存どおりクリア。
