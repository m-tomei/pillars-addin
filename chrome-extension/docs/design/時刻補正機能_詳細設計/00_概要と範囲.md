# 00. 概要と範囲

## 1. 目的

V1.5（`1.5.0`）で以下を実装するための詳細設計を定義する。

- 地方平均時補正（明石・東経135°基準、`Math.round`）
- 標準時からの時差手入力
- 子時切替（23時 / 0時）の2モード
- 大運立運への補正後時分反映
- 結果画面・PNGへの補正情報表示

## 1.1 方法論

**四柱推命（子平法ベース）**。禄命法ではない。

## 2. 前提

| 項目 | 内容 |
|------|------|
| ベース | V1.0（`v1.0.0`） |
| 要件 | `docs/design/時刻補正_v1.5/`（レビュー反映後） |
| 実行環境 | Chrome Extension（オフライン） |
| 日時契約 | JST暦の数値年月日時分。節気は `+09:00` |
| 真太陽時 / DST自動 | 非採用 |

## 3. スコープ

### In

- 入力UI変更（都道府県・時差・子時モード）
- 補正サービスと経度マスタ
- 命式計算への `t_corrected` 適用（時柱・節入り）
- `resolveDayPillarDate` による日柱・時干のみの日跨ぎ
- 大運APIの時分対応と立運への反映
- 結果サマリ表示とPNG内包
- テスト・ユーザー向けドキュメント更新

### Out

- 市区町村経度、海外地名マスタ
- クリップボードへの新フィールド完全対応
- 病薬など他機能
- 禄命法化
- localStorage 永続化（必須としない）

## 4. 成果物

| 種別 | パス（予定） |
|------|----------------|
| 経度マスタ | `chrome-extension/data/prefecture_longitude.json` |
| 補正サービス | `chrome-extension/js/core/TimeCorrectionService.js` |
| 日柱日付解決 | `FortuneCalculator` 内の `resolveDayPillarDate`（モジュールprivateまたは同ファイル関数） |
| テスト | `tests/core/TimeCorrectionService.test.js` 他 |
| UI | `sidepanel.html` / `FormRenderer` / `ResultRenderer` |
| 版表示 | `package.json`, footer → `1.5.0` |

## 5. 用語

要件定義 `01_機能要件_補正ロジック.md` に準拠。日柱日付関数名は **`resolveDayPillarDate` のみ** を用いる。
