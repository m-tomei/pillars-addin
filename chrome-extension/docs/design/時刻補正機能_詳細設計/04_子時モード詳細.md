# 04. 子時モード詳細

## 1. モード定義

| ID | UI表示 | 時支境界 |
|----|--------|----------|
| `switch23` | 23時切替 | 23–0時台＝子、1–2＝丑、… |
| `switch00` | 0時切替 | 0–1＝子、2–3＝丑、…、22–23＝亥 |

既定・未送信: `switch23` / 定義外: InputManager でエラー

## 2. 時支インデックス

`hour` は `t_corrected` の 0–23。分は時支に使わない。

### switch23

```
index = Math.floor(((hour + 1) % 24) / 2)
```

### switch00

```
index = Math.floor(hour / 2)
```

## 3. 日柱日付の解決（名称・契約・確定）

**唯一の名称:** `resolveDayPillarDate`

| 項目 | 内容 |
|------|------|
| 配置 | `FortuneCalculator` 内（privateメソッドまたは同モジュール関数） |
| 公開 | アプリ外部APIとしては非公開。単体テストからは同クラス経由で検証可 |
| 引数 | `(year, month, day, hour, shiMode)` |
| 戻り値 | `{ year, month, day }` |

```js
resolveDayPillarDate(y, m, d, hour, shiMode) {
  if (shiMode === 'switch23' && hour === 23) {
    return DateUtils.addDays(y, m, d, 1);
  }
  return { year: y, month: m, day: d };
}
```

- 適用先: **日柱** と **時干の日干** のみ
- 非適用: 年柱・月柱の節入り、大運立運

## 4. 時干

1. `dayDate = resolveDayPillarDate(...)`
2. `dayStem = calculateDayPillar(dayDate).stem`
3. `hourStem = HOUR_STEM_TABLE[dayStem][index]`

## 5. FortuneCalculator 改修

### calculateHourPillar

```
calculateHourPillar(hour, minute, dayStem, shiMode = 'switch23')
```

### calculateFortune（擬似コード）

```
shiMode = options.shiMode ?? 'switch23'

yearPillar  = calculateYearPillarWithDate(y,m,d,h,mi)   // t_corrected
monthPillar = calculateMonthPillar(y,m,d,h,mi)          // t_corrected

dayYmd = this.resolveDayPillarDate(y,m,d,h,shiMode)
dayPillar = calculateDayPillar(dayYmd.year, dayYmd.month, dayYmd.day)

if h != null:
  hourPillar = calculateHourPillar(h, mi, dayPillar.stem, shiMode)
```

## 6. 表示注記

`switch23` かつ `t_corrected.hour === 23` のとき:

```
注: 23時切替のため日柱は翌日扱い（YYYY-MM-DD）
```
