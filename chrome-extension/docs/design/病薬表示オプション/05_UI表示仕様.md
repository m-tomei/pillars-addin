# 05. UI表示仕様

## 1. 画面構成（変更後）

```text
┌──────────────────────────────────┐
│ 四柱推命 命式計算                 │
├──────────────────────────────────┤
│ 生年月日・時刻入力                │
│  ...入力フィールド...             │
│                                  │
│ ☑ 病薬を表示する（命理正宗）  ←新規 │
│                                  │
│ [ペースト] [クリア] [計算]        │
├──────────────────────────────────┤
│ 命式                    [PNG保存] │
│ ┌ 命式表 ┐                       │
│ │天干…   │  ←常時                 │
│ └────────┘                       │
│                                  │
│ ┌ 病薬診断 ┐  ←オプションON時のみ  │
│ │身旺弱   │                       │
│ │格局(補助)│                      │
│ │病 / 薬  │                       │
│ └─────────┘                      │
│                                  │
│ 大運（基本）                      │
└──────────────────────────────────┘
```

## 2. モード別表示マトリクス

| UIブロック | 命式のみ | 命式+病薬 |
|------------|----------|-----------|
| 入力フォーム | ○ | ○ |
| 病薬オプションスイッチ | ○（OFF） | ○（ON） |
| 命式表 | ○ | ○ |
| 病薬診断セクション | × | ○ |
| 合冲分析セクション | ×（本変更では非表示維持または現状維持※） | ※未決 D-02 |
| 大運基本表 | ○ | ○ |
| 大運吉凶詳細 | ×（既存トグル依存・本変更対象外） | 既存どおり可 |

※ 合冲は現行でも計算後表示がある。本変更で病薬OFF時は合冲計算自体をスキップするため、**合冲セクションも出さない**のが一貫する。

## 3. オプションスイッチUI

| 項目 | 仕様 |
|------|------|
| 要素ID案 | `#byoyaku-option` |
| 種別 | checkbox |
| 配置 | `#fortune-form` 内、ボタン群の直前 |
| ラベル | `病薬を表示する（命理正宗）` |
| 補足文 | 小さく1行: `命式の病と薬を判定します` |
| 初期値 | unchecked |

## 4. 病薬セクションUI

### 4.1 セクション見出し

```text
病薬診断
```

（現行の「格局・病薬 診断」から、病薬主の名称へ変更）

### 4.2 表示ブロック順

1. 身旺弱（補助）  
2. 格局名＋成格／破格（補助）  
3. 病ブロック（1件以上）  
4. 各病に対応する薬ブロック  

### 4.3 病ブロック

| 表示 | 例 |
|------|-----|
| タイトル | 【病】比劫奪財（旺の病・中度） |
| 詳細 | 五行: 木 ／ 十神: 比肩 |

### 4.4 薬ブロック

| 表示 | 例 |
|------|-----|
| タイトル | 【薬】官殺（損の薬）→ 金 |
| 理由 | 官殺で比劫を制し財を護る |
| 所在 | ✓ 命式中に薬あり（時干） / ✗ 命式中に薬なし（行運で補う） |

### 4.5 複数診断

`diagnoses.length > 1` のとき、病1 / 病2 … と番号を付けて縦に並べる（現行踏襲）。

## 5. 結果内トグルの扱い

| 現行 | 変更後 |
|------|--------|
| `#kakkyoku-toggle` + 結果内開閉 | **削除**し、計算前 `#byoyaku-option` に一本化 |
| 結果を一時的に隠したい需要 | 本変更では対応しない（必要なら将来「折りたたみ」を別途） |

## 6. PNG保存

| モード | 含め方 |
|--------|--------|
| 命式のみ | 命式表（＋基本大運がキャプチャ範囲ならその範囲） |
| +病薬 | 命式表 + 病薬セクションを含めて保存できること |

キャプチャ対象要素が結果セクション全体であれば、表示されているブロックのみが入るため追加実装は最小でよい。

## 7. 空状態・エラー

| 状態 | 表示 |
|------|------|
| 未計算 | 結果セクション非表示 |
| 命式成功・病薬失敗 | 命式は表示し、病薬位置にエラーメッセージ |
| クリア | 全結果クリア。オプション値は維持 |
