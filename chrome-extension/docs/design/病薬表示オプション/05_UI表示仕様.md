## 4. 病薬セクションUI

### 4.1 セクション見出し

```text
病薬診断
```

（現行の「格局・病薬 診断」から、病薬主の名称へ変更）

### 4.2 表示ブロック順

1. 気象（寒暖・燥湿。清濁は初版 `不明`）
2. 主軸（格局名＋成格／成格・損傷あり／破格）と用神損傷
3. 身旺弱（補助）
4. 五行偏重・四病四薬の要約（命式全体の分類。病・薬の五行、または処置「琢」）
5. 主軸の病ブロック（1件以上）
6. 各病に対応する主軸の薬ブロック
7. 主軸病薬のバランス
8. 喜忌（主軸・調候）

四病四薬は主軸病薬とは別の判定層であり、両者の病・薬五行が逆になる場合がある。四病四薬側には `【五行偏重】` と「四病四薬による命式全体の分類」の注記を表示し、主軸側の病・薬と混同させない。

喜忌は「主軸の喜」「調候の喜」「主軸の忌」に行を分け、異なる判定層の候補を同じ列挙へ混在させない。

### 4.3 病ブロック

| 表示 | 例 |
|------|-----|
| タイトル | 【主軸の病】比劫奪財（中度） |
| 詳細 | 五行: 木 ／ 十神: 比肩 |

気象由来の病で害をなす五行を特定できない場合、五行欄は表示しない。代わりに取得できる範囲で「原因側」「不足側」を分けて表示し、薬の五行を病の五行として表示しない。

### 4.4 薬ブロック

| 表示 | 例 |
|------|-----|
| タイトル | 【主軸の薬】官殺 → 金 |
| 理由 | 官殺で比劫を制し財を護る |
| 所在 | ✓ 命式中に薬あり（時干） / ✗ 命式中に薬なし（行運で補う） |

### 4.5 複数診断

`diagnoses.length > 1` のとき、主軸の病1 / 主軸の病2 … と番号を付けて縦に並べる（現行踏襲）。気象診断しかない場合は「気象の病」「気象の薬」と表示する。

気象由来の診断は気象ブロックで確認できるため、用神損傷診断がある場合は病／薬ブロックに重複掲載しない。
調候の副薬も同様に気象ブロックに一本化し、診断ごとに同じ内容を繰り返さない。

## 5. 結果内トグルの扱い

| 現行 | 変更後 |
|------|--------|
| `#kakkyoku-toggle` + 結果内開閉 | **削除**し、計算前 `#byoyaku-option` に一本化 |
| 結果を一時的に隠したい需要 | 本変更では対応しない（必要なら将来「折りたたみ」を別途） |

## 6. PNG保存

| モード | 含め方 |
|--------|--------|
| 命式のみ | 命式表（＋基本大運がキャプチャ範囲ならその範囲） |
| +病薬 | 命式表 + 病薬セクションを含めて保存できること |

キャプチャ対象要素が結果セクション全体であれば、表示されているブロックのみが入るため追加実装は最小でよい。

## 7. 空状態・エラー

| 状態 | 表示 |
|------|------|
| 未計算 | 結果セクション非表示 |
| 命式成功・病薬失敗 | 命式は表示し、病薬位置にエラーメッセージ |
| クリア | 全結果クリア。オプション値は維持 |
