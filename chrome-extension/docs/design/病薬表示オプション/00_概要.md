## 1. 目的

1. **命式算出機能を本体機能として明確に切り出す**
2. **命理正宗に基づく病薬の算出・表示をオプション化する**
3. 病薬ロジックに **喜忌篇・継善篇・気象篇** の看命順序と気象／用神損傷を取り込む

## 4. 設計方針（要約）

1. デフォルトは命式算出のみ
2. 病薬ON時は `日干→月令→気象→主軸(継善)→病薬` の順で算出する
3. 既存 `ByoyakuCalculator` を拡張し、気象・用神損傷・月令ブースト從重を追加する
4. 格局別ルールは維持しつつ、気象と矛盾しない薬選定を行う
