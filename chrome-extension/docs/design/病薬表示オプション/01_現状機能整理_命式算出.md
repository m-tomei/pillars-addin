# 01. 現状機能整理 — 命式算出機能（本体）

## 1. 定義

本仕様における **命式算出機能（F-01）** とは、生年月日・時刻・性別から四柱推命の命式を算出し、基本情報として表示する一連の機能を指す。

病薬・格局・合冲・大運吉凶は本体に含めない。

## 2. 入力

| 項目 | 必須 | 現行UI | 備考 |
|------|------|--------|------|
| 生年（西暦） | ○ | `#year` | 1900〜2100 程度 |
| 生月 | ○ | `#month` | 1〜12 |
| 生日 | ○ | `#day` | 1〜31 |
| 出生時 | △ | `#hour` | 任意。時柱算出に必要 |
| 出生分 | △ | `#minute` | 任意 |
| 性別 | ○ | `gender` | 大運の順逆判定に使用 |
| 出生地 | × | `#birthplace` | 表示用。計算には未使用 |
| クリップボード貼付 | − | `#paste-btn` | 入力補助 |

## 3. 算出パイプライン（本体）

```text
入力検証
  → FortuneCalculator.calculateFortune()     … 年・月・日・時柱 + 蔵干
  → JuuniunCalculator.calculateForPillars()  … 十二運
  → TsuuhenCalculator.calculateForPillars()  … 通変星
  → GreatFortuneCalculator.calculateCycles() … 大運サイクル（基本）
  → 命式表・大運表の描画
```

## 4. 出力（本体表示）

### 4.1 命式表

表示順（現行）: 時柱 / 日柱 / 月柱 / 年柱

| 行 | 内容 |
|----|------|
| 天干 | 各柱の干 |
| 地支 | 各柱の支 |
| 蔵干 | 各地支の蔵干 |
| 十二運 | 日干基準 |
| 通変星 | 日干基準（日柱は日主） |

### 4.2 大運表（基本）

- 立運年齢
- 各大運の干支
- **吉凶詳細は本体に含めない**（オプション外・別機能）

### 4.3 付帯機能

- PNG保存（命式結果エリア）
- クリア
- エラー表示

## 5. 現行実装との差分（整理対象）

現行 `AppController.handleCalculate()` は本体に続けて以下も**常時実行**している。

| 順序 | 処理 | 本仕様での扱い |
|------|------|----------------|
| 4.5 | GouChuuCalculator | 本体外（病薬ON時の内部依存候補） |
| 5 | DayMasterStrengthAssessor | 本体外（病薬ON時の内部依存） |
| 6 | KakkyokuCalculator | 本体外（病薬ON時の内部依存） |
| 7 | ByoyakuCalculator | **F-02（オプション）** |
| 8 | DaiunHyoukaCalculator | 本体外（本変更スコープ外） |

本変更後の本体モードでは、上表のうち 4.5〜8 を実行しない。

## 6. 受け入れ基準（本体）

1. 有効な生年月日・性別で四柱が算出される
2. 時刻ありで時柱が算出される／時刻なしで時柱が欠落表示される
3. 蔵干・十二運・通変星が命式表に出る
4. 大運の基本表が出る（吉凶なし）
5. 病薬・格局・合冲・大運吉凶のブロックが**表示されない**
