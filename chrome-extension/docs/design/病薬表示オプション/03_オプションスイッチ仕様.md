# 03. オプションスイッチ仕様（F-03）

## 1. 目的

「命式算出のみ」と「命式算出 + 病薬表示」を、ユーザーが明示的に切り替えられるようにする。

## 2. モード定義

| モードID | 表示名（案） | 挙動 |
|----------|--------------|------|
| `meishiki_only` | 命式算出のみ | F-01 のみ実行・表示 |
| `meishiki_with_byoyaku` | 病薬を表示 | F-01 + F-02 を実行・表示 |

デフォルト: **`meishiki_only`**（本体に絞る方針）

## 3. UI配置

### 3.1 推奨配置

**計算実行前に見える位置**（入力フォーム内、または結果ヘッダ直上）に置く。

理由:

- 現行の「格局・病薬診断」トグルは結果表示後の開閉のみで、計算制御になっていない
- 本仕様のスイッチは **計算パイプラインの分岐** を担うため、入力〜計算の近くに置く

### 3.2 コントロール種別

| 案 | 形式 | 採用 |
|----|------|------|
| A | チェックボックス「病薬を表示する」 | **採用（推奨）** |
| B | ラジオ「命式のみ / 命式+病薬」 | 代替可 |
| C | 結果エリア内の表示トグルのみ | **不採用**（計算制御にならない） |

推奨ラベル:

```text
□ 病薬を表示する（命理正宗）
```

- OFF = `meishiki_only`
- ON  = `meishiki_with_byoyaku`

### 3.3 現行トグルとの関係

| 現行UI | 本変更後 |
|--------|----------|
| `#kakkyoku-toggle`（結果内・表示開閉） | **廃止または降格**。計算制御スイッチへ置き換え |
| `#gouchuu-toggle` | 本変更では触らない（スコープ外） |
| `#great-fortune-toggle` | 本変更では触らない（スコープ外） |

方針: 病薬については「計算前オプション」を正式スイッチとし、結果内の単なる表示トグルと二重管理しない。

## 4. 状態管理

### 4.1 保持場所

| 方式 | 内容 | 採用 |
|------|------|------|
| セッション内メモリ | AppController / FormRenderer のプロパティ | **必須** |
| `chrome.storage.local` | 再起動後も前回値を復元 | **推奨** |
| URLクエリ等 | 不要 | 不採用 |

キー案: `feature.byoyakuEnabled`（boolean）

### 4.2 状態変更タイミング

| 操作 | 挙動 |
|------|------|
| スイッチON/OFF（未計算） | フラグのみ更新。表示変化なし |
| スイッチON/OFF（計算済） | **再計算を促す**、または自動再計算 |
| 計算ボタン押下 | 現在フラグに従いパイプライン分岐 |

**推奨**: 計算済状態でスイッチを変えたら **自動再計算**（入力が有効な場合）。  
無効入力ならフラグだけ更新し、次回計算に反映。

## 5. 計算分岐ルール

```text
if byoyakuEnabled == false:
    実行: Fortune → Juuniun → Tsuuhen → GreatFortune(basic)
    表示: 命式表 + 基本大運
    非実行: GouChuu / Strength / Kakkyoku / Byoyaku / DaiunHyouka
else:
    実行: 上記 + GouChuu + Strength + Kakkyoku + Byoyaku
    表示: 命式表 + 基本大運 + 病薬セクション（補助として身旺弱・格局を含めてよい）
    非実行（本変更）: DaiunHyouka  ※スコープ外のため、当面は実行しても非表示、または実行スキップを選択
```

### 5.1 大運吉凶についての暫定方針

本変更のスイッチは「病薬表示」専用とする。  
`DaiunHyoukaCalculator` は病薬結果に依存するため、

- **推奨**: 病薬OFF時は実行しない／表示しない  
- 病薬ON時も、大運吉凶は既存トグル `#great-fortune-toggle` のまま（本仕様では仕様変更しない）

実装時の選択は [06_実装計画と未決事項.md](./06_実装計画と未決事項.md) の未決事項 D-01 を参照。

## 6. アクセシビリティ・文言

| 項目 | 内容 |
|------|------|
| 説明文（短） | 「命理正宗の病薬説に基づき、病と薬を判定します」 |
| ツールチップ | 從重者論・四病四薬の簡易説明へのリンクは任意 |
| デフォルトOFFの理由 | まず命式確認を主用途とし、診断系は明示オプトイン |

## 7. 受け入れ基準

1. 初回表示（またはストレージ未設定）で病薬オプションはOFF  
2. OFFで計算すると病薬UIが出ない  
3. ONで計算すると病薬UIが出る  
4. ON→OFF（または逆）で再計算後の表示がモードと一致する  
5. 永続化を実装する場合、再起動後も前回選択が復元される
