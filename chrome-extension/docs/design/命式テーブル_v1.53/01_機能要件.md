# V1.5.3 機能要件（確定）

版表記: `package.json` / `manifest.json` / フッタ → **1.5.3**

## 目的

命式テーブルの四柱（時・日・月・年）の列幅を、蔵干の個数（1〜3）に依存せず等幅にする。

## 要件

- 四柱の列幅は常に 25% ずつ（`table-layout: fixed`）
- 蔵干が1個（例: 子→癸）でも3個（例: 寅→甲丙戊）でも、列幅は変わらない
- 計算ロジック（補正・子時・大運・蔵干の中身）は V1.5.2 から変更しない
- PNG 保存のキャプチャ対象も同じテーブルのため、画面と PNG の両方で等幅になる

## 非対象

- 蔵干の表示内容・順序・区切り文字の変更
- 通変星・十二運の算出変更
- 入力UIの変更
