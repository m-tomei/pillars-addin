# V1.5.2 機能要件（草案・確認待ち）

ベース: V1.5.0
版表記: `package.json` / `manifest.json` / フッタ → **1.5.2**
範囲: **見た目と入力操作のみ**。命式・大運・補正の計算式は V1.5 から変更しない。
方法論: 四柱推命（子平法）

---

## 1. 確定した変更

### 1.1 入力欄の1行化

- 生年月日: **年・月・日を1行**（折り返さない）
- 出生時刻: **時・分を1行**（「時刻不明」チェックも同じ行）

サイドパネル幅でも折り返さない。入力欄は縮めてラベル（年/月/日/時/分）を横に置く。

### 1.2 時刻不明チェック

出生時刻の横に「時刻不明」チェックボックスを置く。

計算への意味は現行の「時が空」と同じ。

- 補正しない（`applied: false`, `reason: 'no_time'`）
- 時柱なし
- 大運は入力年月日 **12:00**

### 1.3 出生地「手動」と時差の表示切替

都道府県セレクトに **「手動」** を追加する。

- **手動以外**（47都道府県のいずれか）: 「標準時からの時差」を **非表示**。時差は **+0:00**
- **手動**: 時差欄を **表示**。経度補正はしない（現行の都道府県未選択と同じ）

### 1.4 出生地の初期値

初期値・リセット後は **東京都**（コード `13`）。経度補正 +19分が既定。

### 1.5 時差ヘルプを短く

手動選択時だけ見える。案:

`海外出生のみ入力。夏時間は時差に含めてください。`

（確定文面は実装時にこの案でよいか確認）

### 1.6 変えないもの

- 東京 +19分、明石 135°E、真太陽時なし
- `switch23` の 23時台日跨ぎ
- `resolveDayPillarDate` は日柱・時干のみ
- 結果サマリ・PNG・子時ヘルプ・計算ボタンより下

## 3. 入力から計算への対応（提案）

| UI | `prefectureCode` | `offsetMinutes` | hour/minute |
|----|------------------|-----------------|-------------|
| 都道府県（例: 東京） | そのコード | 0（欄は非表示） | 通常入力 |
| 手動 | `null` | 時差欄の値 | 通常入力 |
| 時刻不明 ON | （上記どおり） | （上記どおり） | `null` / `null` |

クリップボード貼り付け: 時刻が取れたら時刻不明 OFF、取れなければ ON。都道府県・手動・時差は貼り付け対象外（V1.5どおり手入力）。
