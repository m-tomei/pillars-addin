# Calculation Algorithms

本アプリケーションで使用されている四柱推命（子平法）の計算アルゴリズムについての解説です。禄命法ではありません（年柱中心・通変星不使用にはしません。日干を主体とします）。

バージョン **1.5.0** では、入力時計時刻に時差と地方平均時補正を加えた `t_corrected` を命式・大運の基準にします。

## 1. 暦と節入り

本システムは、太陽の黄経に基づく二十四節気（定気法）を使用しています。
国立天文台などが公開している計算式またはデータに基づき、分単位で節入り時刻を判定しています。

節気ISO（`+09:00`）はオフセットを削らず、JST epoch で比較します。OSローカルの `new Date(y, m-1, ...)` による加減算は使いません。

- **年の区切り**: 立春（2月4日頃）の節入り時刻
- **月の区切り**: 各月の節入り時刻（啓蟄、清明、...）

### 年柱の計算

1. 入力された日時（時刻ありなら `t_corrected`）が、その年の「立春」の節入り時刻より前か後かを判定します。
2. 立春前であれば前年の干支、立春後であればその年の干支を採用します。
   - 例: 2024年2月1日は、まだ立春前なので2023年（癸卯）として扱われます。
3. `resolveDayPillarDate` は年柱には使いません。

### 月柱の計算

1. 入力された日時（時刻ありなら `t_corrected`）が、どの節気に入っているかを判定し、月支（寅、卯...）を決定します。
2. 年干と月支から、五虎遁年起月訣（年干から月干を求める法則）を用いて月干を決定します。
3. `resolveDayPillarDate` は月柱には使いません。

## 2. 時刻補正

時刻が入力されているときだけ補正します。補正量 0 でも `applied: true` です。

```
offsetMinutes = 時差（出生地の時計を JST に合わせる分。範囲 ±23:59）
longitudeOffsetMinutes = Math.round(4 * (lon - 135))
t_corrected = 入力日時 + offsetMinutes + longitudeOffsetMinutes
```

- 基準子午線は明石・東経135°。東京都（東経139.6917°）は **+19分**。
- 都道府県未選択なら経度補正は 0 分。
- 真太陽時は対象外。夏時間の自動判定はせず、必要な差は時差へ手入力します。
- 加減算は数値カレンダー（`DateUtils.addMinutes` / `addDays`）で行い、月末・年末・閏日を跨ぎます。

時刻未入力のとき:

- 補正しない（`applied: false`, `reason: 'no_time'`）
- 時柱なし
- 年柱・月柱・日柱は入力年月日
- 大運だけ入力年月日の **12:00** で立運する（Calculator 内で時刻を推測しない）

## 3. 日柱と時柱

### 子時モード

| モード | UI | 時支 |
|--------|-----|------|
| `switch23`（既定） | 23時切替 | 23–0時台＝子、1–2＝丑、… |
| `switch00` | 0時切替 | 0–1＝子、2–3＝丑、…、22–23＝亥 |

時支の `hour` は `t_corrected` の 0–23。分は時支に使いません。

### 日柱日付の解決（`resolveDayPillarDate`）

`switch23` かつ `hour === 23` のときだけ、暦日を翌日へ進めます。それ以外は年月日をそのまま返します。

- **適用先**: 日柱、および時干を決めるときの日干
- **非適用**: 年柱・月柱の節入り、大運立運

V1.0 は 23時台でも日柱を進めません。V1.5 の `switch23` は進めます。

### 日柱

- 1900年1月1日（甲戌）を基準日とし、JST暦日の差から60干支を算出しています。
- 日柱の暦日は `resolveDayPillarDate` の結果です（時刻なしなら入力年月日）。

### 時柱

- 時刻があるときだけ算出します。
- 日干は `resolveDayPillarDate` 後の日柱の干を使い、五虎遁日起時訣で時干を決めます。

## 4. 大運（Taiun / Great Fortune）

10年ごとの運勢サイクルを計算します。

### 順行・逆行の判定

- **陽男陰女**（陽の年に生まれた男性、陰の年に生まれた女性）: **順行**
- **陰男陽女**（陰の年に生まれた男性、陽の年に生まれた女性）: **逆行**
- 陽の年: 天干が甲・丙・戊・庚・壬
- 陰の年: 天干が乙・丁・己・辛・癸

### 開始年齢（立運）の計算

- **順行**: 生まれた日時から「次の節入り」までの経過時間を計算し、3で割ります。
- **逆行**: 生まれた日時から「前の節入り」までの経過時間を計算し、3で割ります。
- 距離は暦日の整数差ではなく、`getElapsedDays` の **小数日**（epoch差 / 86400000）です。
- 端数は四捨五入します（例: 2.6 -> 3歳運）。
- **時刻あり**: `t_corrected` の時分を使います。子時モードによる人工+1日は適用しません。
- **時刻なし**: 入力年月日の **12:00** を使います。

表示年（大運カードの西暦）は、補正適用時は `t_corrected.year`、未適用時は入力年です。

## 5. 蔵干と通変星

- **蔵干**: 各地支に含まれる干（本気・中気・余気）のうち、主となるものを採用しています（本システムでは簡易化のため、月律分野蔵干の詳細な日数計算までは行わず、主要な蔵干を表示します）。
- **通変星**: 日干（自分）と他の干との五行関係（生・剋・比）および陰陽の関係から算出します。

## 6. 十二運

- 日干から見た各支のエネルギー状態（長生、沐浴...）を表組みデータから参照します。

## 7. 日時の役割分担

| 用途 | 時刻あり | 時刻なし |
|------|----------|----------|
| 時差・経度合成結果 | `t_corrected` | なし（`applied: false`） |
| 年柱・月柱の節入り | `t_corrected` | 入力年月日 |
| 大運の節までの距離 | `t_corrected` の小数日 | 入力年月日 12:00 |
| 日柱の暦日 | `resolveDayPillarDate(...)` | 入力年月日 |
| 時支 | `t_corrected.hour` + `shiMode` | なし |
| 時干の日干 | 日柱日付の日干 | なし |
