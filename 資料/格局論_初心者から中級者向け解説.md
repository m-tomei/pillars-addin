# 格局論を初心者から中級者向けにわかりやすく学ぶ

## はじめに

この文書は、[命理正宗_第2部_核心理論篇.md](C:\Users\morikoshi\CEIS Dropbox\Morikoshi Masahide\Test2\命理正宗\命理正宗_第2部_核心理論篇.md) で整理された動静説・蓋頭説・病薬説を土台にしつつ、[命理正宗_概要.md](C:\Users\morikoshi\CEIS Dropbox\Morikoshi Masahide\Test2\命理正宗\命理正宗_概要.md) および [神峰通考_命理正宗_原文.md](C:\Users\morikoshi\CEIS Dropbox\Morikoshi Masahide\Test2\命理正宗\神峰通考_命理正宗_原文.md) の格局部分を参照して、初心者から中級者向けに再構成した解説である。

第2部の最後では、張楠の核心理論が次のように第3部へ展開すると整理されている。

- 動静説・蓋頭説: 各格局の用神が天干に透出しているかを見る
- 病薬説: 各格局の病と薬を定める
- 四病四薬説: 行運での吉凶を見る

つまり格局論は、これまで学んだ理論を実際の命式へまとめて適用する場である。

初学者向けに一言でいえば、

```text
格局 = この命式を何を主軸に読めばよいかを定める枠組み
```

である。

## 1. 格局とは何か

「格局」という言葉は、初心者には「格の名前を当てる作業」のように見えやすい。しかし命理正宗の文脈では、格局とは単なるラベルではない。

格局が教えてくれるのは、主に次の3点である。

- この命式で中心になる気は何か
- その中心をどの十神として読むか
- その中心をどう活かし、何がそれを壊すのか

言い換えると、格局は命式の「診断の枠組み」である。

以前のやり取りで使った医療の比喩を使えば、

- 格局論: 体質と病型を見立てる
- 病薬説: その病型に対する処方を考える

という関係になる。

## 2. 格局を学ぶと何が変わるのか

動静説と蓋頭説だけを学んだ段階では、

- 何が表に出ているか
- どの層で作用しているか

は見やすくなる。

病薬説を学ぶと、

- 何が病か
- 何が薬か

という吉凶の基準が見えてくる。

そして格局論を学ぶと、

- そもそもこの命式をどの主軸で読むべきか
- 財官印食傷比劫のうち、どれを中心に命式が組み立っているか

が整理しやすくなる。

初学者向けに言えば、

```text
動静説 = 作用の層を見る
蓋頭説 = 表面に何が出るかを見る
病薬説 = 何が病で何が薬かを見る
格局論 = その命式の主軸を定める
```

という役割分担である。

## 3. 基本原則: 日干為主・月令為提綱

命理正宗の概要では、張楠の核心思想として次の一句が引かれている。

> 「欲知貴賤、先観月令乃提綱。次断吉凶、専用日干為主本」

これを初学者向けにほどくと、

- 日干は「自分そのもの」
- 月令は「その命式の季節的主権」

ということである。

したがって格局を見るときは、まず次の順で考える。

1. 日干は何か
2. 月令は何か
3. 月令がどの十神として日干に関わるか
4. その気が天干に透っているか
5. それが純か、混じるか、破られるか

ここで大切なのは、格局は日干抜きでは決まらないという点である。

たとえば月令が同じ酉でも、

- 甲日なら酉金は官殺側
- 壬日なら酉金は印側

になる。

つまり格局は、

```text
月令だけで決まるのではなく
日干から見た月令の意味で決まる
```

のである。

## 4. 月令が「提綱」である理由

なぜ月令がそれほど重いのか。これは病薬説でも繰り返し出てきたように、月令がその季節の司令だからである。

同じ五行でも、

- 月令を得ているもの
- 月令を得ていないもの

では勢いが大きく違う。

そのため格局論では、まず月令に何があるかを見る。これは「その命式の現場責任者は誰か」を見るのに近い。

初心者向けには、次のイメージで覚えるとわかりやすい。

- 日干: 本人
- 月令: 本人が置かれている季節と環境
- 格局: その環境の中で、何を主題として生きる命式か

## 5. 格局と用神・病薬の関係

ここは混同しやすいところなので、分けて整理しておく。

| 項目 | 役割 | 何を決めるか |
|------|------|--------------|
| 格局 | 診断の枠組み | 命式の主軸 |
| 用神 | その格局を成り立たせる鍵 | 何を活かすか |
| 病薬 | 問題点と治し方 | 何が壊し、何が救うか |

たとえば正官格なら、

- 格局: 正官格
- 用神の方向: 官を活かすこと
- 病: 官を傷つけるもの、官が弱すぎること、官が多すぎること
- 薬: その病に応じて財・印・食神などが変わる

となる。

つまり、

```text
格局で主軸を定め
病薬でその主軸の健康状態を見る
```

という順番である。

## 6. 格局を見る基本手順

初心者は、いきなり特殊格局へ飛ばない方がよい。まずは次の手順で「普通の読み」を固めるのがおすすめである。

### Step 1. 日干を決める

まず日干を中心に据える。これが命主である。

### Step 2. 月令を十神へ変換する

月支の本気を、日干から見た十神に置き換える。

例:

- 甲日で酉月なら、酉の主気は辛金で正官
- 甲日で午月なら、午の主気は丁火で傷官
- 丙日で寅月なら、寅の主気は甲木で偏印

### Step 3. その気が天干に透っているかを見る

ここで動静説と蓋頭説が入る。

- 月令に正官があっても、天干に透らないなら表面化は弱め
- 月令の用神が天干に透れば、頭面に出て格が立ちやすい

### Step 4. 混じりと破れを見る

たとえば正官格でも、

- 傷官が強く透る
- 官が多すぎて殺化する
- 印がなく官が孤立する

なら、きれいな正官格としては読みにくくなる。

### Step 5. 病と薬を定める

格局が見えたら、次に病薬説を使う。

- 何がその格を壊しているか
- 何がその格を助けているか

を見る。

### Step 6. 行運で成否を見る

最後に大運・年運で、

- 用神が助かるか
- 病が強まるか
- 蓋頭で何が表に出るか

を見る。

## 8. 具体例1: 正官格をどう読むか

[神峰通考_命理正宗_原文.md](C:\Users\morikoshi\CEIS Dropbox\Morikoshi Masahide\Test2\命理正宗\神峰通考_命理正宗_原文.md) の正官格では、月令の正官をどう使うかが中心に語られている。張楠は、月上の官星をそのまま機械的に良いとせず、

- 官が軽いのか重いのか
- 日主が旺か弱か
- 財で官を生じるべきか
- 官が重すぎて殺化するなら、食神で官殺を制すべきか

を病薬的に見ている。

原文の核心は次の一文にまとまっている。

> 「要官星有病、各因病而薬之。官旺官多、喜食神以制去之。官星気弱、喜財神以生之」

つまり正官格は、

- 官が弱ければ財で生じる
- 官が重すぎれば食神で制する

というように、病に応じて読み分ける格なのである。

### 学習用の仮例

```text
年柱: 戊辰
月柱: 辛酉
日柱: 甲寅
時柱: 癸巳
```

読み方:

- 日干は甲木
- 月令は酉金
- 酉の主気は辛金
- 甲から見て辛は正官
- 年干の戊土は偏財
- 時干の癸水は正印

したがって、まず正官格として見る。

次に細かく見ると、

- 月干にも辛金が透っている
- これは官星が頭面に出ている形
- 年干に戊土が透り、偏財として官星を生じる
- 時干に癸水が透り、正印として日主を助ける
- 日支寅があり、甲木にも根がある

ので、官だけに押しつぶされる形ではない。

天干の並びを十神で言えば、

```text
戊（偏財） → 辛（正官） → 癸（正印） → 甲（日主）
```

という流れがあり、財官印がそろっている形である。

このときの基本的な見方は、

- 官が秩序を与える
- 財が官を生じる
- 官が印を生じる
- 印が日主を助ける

である。

もしここに強い丁火傷官が透れば、

- 傷官見官
- 官格の病

として見やすくなる。

逆に癸水や壬水の印がしっかりあり、木にも根があるなら、

- 官印相生
- 官が身を害するのでなく、秩序と助力として働きやすい

という読みになる。

正官格の古歌も、まずはこの感覚で読むとよい。

> 「正気官星月上推、無沖無破始為奇。中年歳運来相助、将相公侯総可為」

### この例で以前の理論をどう使うか

- 動静説: 辛金と他天干の関係は天干同士で見る
- 蓋頭説: 辛金が月干に透っているので、官の性質が表面に出る
- 病薬説: 傷官が来れば病、印や財の助けがあれば薬になりうる

## 9. 具体例2: 傷官食神格をどう読むか

張楠は傷官食神格で、「傷官見官。為禍百端」の理をかなり丁寧に説明している。原文では、傷官とは官を傷つけるだけでなく、

> 「不服官管，如弒殺上官之類」

とたとえられている。つまり、上官に服さず、ついには上官を害するような性質として描かれているのである。だから傷官見官が深刻な問題として語られる。

ただしここでも、命理正宗の特徴は「傷官は悪い」で止めないことにある。

- 傷官が真か假か
- 日主が強いか弱いか
- 印で破るべきか
- 財で活かすべきか

を見ている。

さらに原文では、真傷官と假傷官の区別がかなり重要である。

- 真傷官: 甲乙日が巳午未月に生まれ、火が本格的に用事して木を焚く形
- 假傷官: 甲乙日が寅卯月に生まれ、火が虚火として木の精英を洩らす形

この違いによって、同じ「火」が来ても意味が変わる。

- 真傷官は、火が強すぎれば木を傷めるので、水印で救う方向になりやすい
- 假傷官は、木火通明の方向で働くので、南方火運で発達しやすい

原文の口訣を一言で言えば、

```text
假傷官は傷官運で発し
真傷官は傷官運で滅びやすい
```

という違いである。

### 学習用の仮例

```text
年柱: 壬子
月柱: 丙午
日柱: 甲寅
時柱: 己未
```

読み方:

- 日干は甲木
- 午月の主気は丁火
- 甲から見て丁は傷官

よって、まず傷官格として考える。

この命式では、

- 月干には丙火が透っており、これは甲木にとって食神
- 月令の午の主気は丁火で、こちらは傷官
- 日支寅で甲木にも根がある

ので、午月の傷官を中心にしつつ、食神も並ぶ火の洩気が強い形として読む。

ここへ辛金の正官が強く透れば、

- 傷官が官を傷つける
- 傷官見官の病

となりやすい。

しかし、

- 印が来て傷官を制する
- あるいは比劫過多で財が弱い局面で、官が比劫を制して財を守る

なら、同じ官でも意味が変わってくる。

ここが、張楠がいう「前後進退」の読みである。原文では、日主生旺で比肩が多く財が弱いなら、傷官格でも官星を喜ぶことがあると述べる。官が比劫を制して財星を存するからである。つまり、

```text
同じ十神でも
命式全体の前後関係で吉凶は変わる
```

のである。

## 10. 具体例3: 印綬格をどう読むか

印綬格は、初心者が「印は全部良い」と思い込みやすい格局である。しかし張楠は、印が多すぎれば補薬過多のようになり、かえって病になると述べている。

### 学習用の仮例

```text
年柱: 乙卯
月柱: 甲寅
日柱: 丙午
時柱: 壬辰
```

読み方:

- 日干は丙火
- 寅月の主気は甲木
- 丙から見て甲は偏印

よって、まず偏印の格として見る。なお命理正宗の第18章は「印綬格」という章名で、実際には正印と偏印をあわせて論じている。そのため本書の文脈では、広く印の格として読んでよい。

この例では、

- 月干に甲木が透っている
- 年支卯、月支寅で木の根もある
- 丙火は木から助けられる

ので、印の扶助がかなり強い。

ここに官星が適度にあれば、

- 官印相生

としてまとまりやすい。

しかし、さらに木印が重なりすぎて身も旺じすぎると、

- 補いすぎ
- 印多為病

の方向へ傾く。

このとき財が来て印を破れば、かえって薬になることがある。ここが病薬説との接点である。

### 真印と假印

原文では、印綬格にも真印と假印の区別があると説かれている。

- 真印: 印の根が厚く、実力がある
- 假印: 月令上は印でも、根が衰えていて力が浅い

たとえば原文では、丙日が亥月に生まれる例を假印として挙げている。亥中には甲木があり、十神上は印に見える。しかし亥月は十月で、木気は根が枯れ葉が落ちる季節とされる。つまり、

- 印の名前はある
- だが季節的に木が衰えていて実力が浅い

ので、假印になるのである。

ここでもやはり、

- 月令
- 透干
- 根
- 季節

をまとめて見ないと、格局名だけで誤る。

印綬格の古歌も、方針をつかむ助けになる。

> 「月逢印綬喜官星、運入官郷福必清。死絶運臨身不利、後行財運百無成」

また偏印については、原文の末尾で梟印の性質にも触れている。

> 「印星偏者是梟神，柱内最喜見財星」

実践上は、偏印が強い場合には食神との関係や、財が梟印をほどく役目を持つかどうかも中級者の重要な論点になる。

## 11. 雑気格はなぜ難しいのか

初心者が早くつまずきやすいのが、辰戌丑未の雑気格である。

これはなぜ難しいかというと、

- ひとつの地支の中に複数の蔵干がある
- どれを主軸に取るかが単純ではない
- 透干の有無で主役が変わりやすい

からである。

たとえば戌月なら、

- 戊土
- 辛金
- 丁火

が雑蔵される。

このとき、

- 戊が透るのか
- 辛が透るのか
- 丁が透るのか

で表面の顔つきが違ってくる。

さらに、辰戌丑未は墓庫でもあるので、動静説で学んだ「冲で開く」という視点も重要になる。命理正宗では、墓庫は対冲でなければ開きにくいと整理されていた。したがって雑気格では、

- 何が透っているか
- 墓庫が冲で開く局面があるか

の両方を見た方がよい。

ここでは、これまで学んだ理論がそのまま総動員される。

- 動静説: 蔵干を勝手に外へ引っぱり出さない
- 蓋頭説: 何が天干に出ているかを重視する
- 病薬説: その透出した主軸にとって何が病かを見る

つまり雑気格は、格局論の応用問題なのである。

## 12. 特殊格局はどう扱うべきか

[命理正宗_第1部_理論批判篇.md](C:\Users\morikoshi\CEIS Dropbox\Morikoshi Masahide\Test2\命理正宗\命理正宗_第1部_理論批判篇.md) で張楠は、理に合わない特殊格局をかなり厳しく批判している。

たとえば、

- 日貴格については、貴人だけを見て財官印星を論じない点を虚誕とする
- 魁罡格については、「なぜ四墓の上にあるだけで威権を取れるのか」と大謬とする

という具合である。

したがって初心者のうちは、

- 珍しい格局名を当てること

よりも、

- 月令を基準に正格を取る
- その格の病と薬を明確にする

方がずっと大切である。

命理正宗の読み方としては、

```text
まず正格を固め
理に合うものだけ特殊格局として認める
```

くらいの姿勢が安全である。

## 13. 初心者がつまずきやすい誤解

### 誤解1. 格局は格の名前を当てれば終わり

違う。格局は入口であって、そこから

- 用神
- 病薬
- 行運

へ進まないと判断にならない。

### 誤解2. 月令だけ見れば格局は決まる

月令は提綱だが、

- 日干との関係
- 透干
- 混雑
- 破れ

を見なければならない。

### 誤解3. 格局が決まれば吉凶も自動的に決まる

決まらない。

- 同じ正官格でも、官が弱ければ財が薬になる
- 官が多すぎれば食神が薬になる
- 傷官格でも、状況次第で官が薬になることがある

この柔軟さが命理正宗の特徴である。

### 誤解4. 格局と病薬は別々の話である

別々ではない。

- 格局は主軸
- 病薬はその主軸の健康診断

である。

### 誤解5. 格局は月支の蔵干を自由に取り出して決めればよい

これも違う。

- 月令の主気を中心に見る
- 透干しているかを確かめる
- 雑気なら何が重いかを慎重に見る

という順番が必要である。

## 14. 第2部の諸理論とのつながり

格局論は、単独では使いにくい。むしろ次の理論がそろってはじめて働きやすい。

| 理論 | 格局論での役割 |
|------|----------------|
| 動静説 | 天干作用と地支作用を混同しない |
| 蓋頭説 | 用神や病神が表面に出ているかを見る |
| 六親説 | 各格局が六親にどう現れるかを見る |
| 病薬説 | 格局の病と薬を決める |
| 格局論 | 命式の主軸を定める |

これを一つの流れで書くと、

```text
月令から格局を定める
↓
その格局の用神と病を決める
↓
何が天干に出ているかをみる
↓
行運で病が増えるか薬が来るかをみる
```

となる。

## 15. 中級者への橋渡し

この段階で次に深めるなら、次の順がおすすめである。

1. 正官格・財格・印綬格・傷官食神格を一つずつ確実に読む
2. 真と假、純と雑、成格と破格の違いを覚える
3. 雑気財官印綬格へ進む
4. その後に特殊格局へ入る

特に中級者へ進む鍵は、

- 格局名の暗記

ではなく、

- なぜその格になるのか
- 何がその格を破るのか
- 何がその格を救うのか

を自分の言葉で言えるようになることである。

## まとめ

格局論を一言でまとめると、

```text
月令を提綱として
この命式の主軸を定める理論
```

である。

そして命理正宗の文脈では、格局は単体では完成しない。

- 動静説で作用の層を見分け
- 蓋頭説で表面に何が出るかを見て
- 病薬説でその格の病と薬を定める

ことで、はじめて実際の吉凶判断へ進める。

初心者のうちは、まず

- 日干を見る
- 月令を見る
- 月令を十神へ変換する
- 透干を確かめる
- 病と薬を考える

という5段階を丁寧に繰り返すのが最短である。

格局は「難しい分類学」ではなく、「命式の中心線を見失わないための道しるべ」として学ぶと理解しやすい。
